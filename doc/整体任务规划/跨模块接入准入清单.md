## 1. 准入级别

| 级别 | 含义 | 允许行为 | 不允许宣称 |
|---|---|---|---|
| A0 语义可评审 | 职责、依赖、关键字段仍有歧义 | Review、提出问题 | 不可开始依赖该语义的实现 |
| A1 可按文档开发 | 关键语义已 accepted；字段、错误、边界、Schema/Golden 或明确测试矩阵足以让生产方实现 | 模块可开始 DTO/Adapter/Handler 实现；可并行补 CI | 不代表跨模块联调通过、契约 frozen 或生产可用 |
| A2 可联调验收 | 生产方 Schema/Golden/Contract Test 已进入 CI；消费者映射和 Fault/身份/时间语义有真实测试 | 开始跨模块集成、端到端验收 | 不代表真实环境 Secret、网络、权限与竞态已完成 |
| A3 生产接入通过 | A2 通过，真实部署配置、凭据轮换/撤销、网络出口、安全和并发边界完成演练 | 允许进入受控生产使用 | 不允许超出授权范围或把历史授权当永久许可 |

## 3. 跨模块一致性决议

1. **认证与授权分层。** Data 同进程调用由 Root Server 已认证的 Principal/Scope Context 建立可信 caller，不使用 Data API Key；远程 HTTP Adapter 才保留 Data API Key 认证。Platform Service Secret、Owner Token、Provider Token 与 Data API Key 不得复用。浏览器不得接触任何服务端 Secret。
2. **主体一致性。** GOV-CTR-006 的 `subject_ref` 必须来自可信认证上下文。Data 使用认证后 principal；News 使用可信 caller；Quant/Research MVP 使用 Researchflow service principal。禁止请求体、Query 或任意 Header 自报主体。
3. **资源一致性。** Data 的 `resource_ref` 指向内容寻址 Snapshot Manifest；News 指向不可变 Evidence 版本；Quant 指向内容寻址 Result Manifest；Research 指向 Evidence ID。资源引用必须唯一绑定实际被授权对象。
4. **策略版本一致性。** `policy_version` 只能指向 GOV-CTR-006 AuthorizationPolicySnapshot.snapshot_ref。组合策略必须完整记录所有实际生效的策略版本，按 `(policy_type, policy_ref, policy_version)` 字典序排序且去重。Fingerprint 必须由公共算法从 AuthorizationRef + PolicySnapshot 重建，领域模块不得自行定义变体。
5. **内容级别一致性。** News 的 requested_content_level 不得高于授权 content_level；高于时拒绝请求，不得静默降级。Research 派生内容不得高于任一上游来源许可级别；Research 自身 allowed 不能覆盖上游撤销/拒绝。
6. **时间一致性。** 所有 Evidence/Result/Manifest 继承同一 Run 的 system_as_of；system_observed_at 记录实际观察时间，不得回填。严格 PIT 下 available_at 未知或晚于 system_as_of 的事实不能作为当时可用事实。
7. **读取一致性。** AuthorizationRef 是审计快照，不是 bearer token。每次读取按来源 Owner 当前策略复核；授权检查与正文读取之间策略变化时重新授权，无法证明一致性则 fail closed。
8. **故障一致性。** 认证失败 401、Scope/策略拒绝 403、授权依赖不可用 503；不得把认证/授权故障记为 Provider 不可用，也不得回退历史 allowed 或缓存正文。

## 5. 接入前必须执行的 Review

- [ ] 模块 Owner 对照本目录确认自己是唯一生产方，不复制其他模块策略判断。
- [ ] 对照 Schema、Golden 和字段表核对 required/nullable/enum/时间/单位，不以 Go 零值猜测 null/缺失。
- [ ] 把跨对象绑定规则写成 Validator/Contract Test；JSON Schema 不承担跨文件、跨字段或运行时授权判断。
- [ ] 对所有受限资源验证历史 allowed、过期、撤销、unknown、授权服务不可用和并发竞态。
- [ ] Data 同进程验证 Principal/Scope Context 不可伪造、purpose Scope 与读取时授权复核；仅远程 Adapter 验证 X-API-Key Header 冲突/轮换/撤销；News 验证 Provider/Source/Endpoint 三类策略组合。
- [ ] 消费者只持有不透明 AuthorizationRef；读取时调用 Owner 当前授权检查，不把引用当 bearer token。
- [ ] 将测试命令、CI Run、结果、提交 SHA 记录到模块验收证据；未记录不得升级 frozen。

- 当前 A1 只表示可按文档开始实现，不表示 A2 跨模块联调准入已全部满足。
- GOV-CTR-006、DATA-CTR-008、NEWS-CTR-002、QNT-CTR-005、RSC-CTR-001 和 PLAT-CTR-001～007 均不得因本清单建立而自动升级为 frozen。
