# 整体任务规划文档索引

本目录按主题归类。跨模块联调与收尾工作统一以 [06-联调收尾](./06-联调收尾/README.md) 为唯一任务入口。

## 阅读顺序

1. [项目总览](./01-项目总览/整体任务规划总览.md)：项目目标、架构、模块边界和总体执行路线。
2. [契约治理基线](./02-契约治理/跨模块统一契约制定规范与治理基线.md)：契约制定、冻结、变更和权威性规则。
3. [项目级契约登记簿](../contract/PLAT-002-项目级契约冻结登记簿.md)：项目级契约编号、生产方/消费者、状态和证据门禁。
4. [模块接口契约](./03-模块接口契约/)：跨模块 DTO、ApplicationPort 与接口约束。
5. [架构方案](./04-架构方案/)：模块化单体、公共平台、诊断和迁移方案。
6. [治理与验收历史](./05-治理与验收/)：治理规范、历史 Review、独立验收和冻结记录。
7. [联调收尾](./06-联调收尾/README.md)：当前 repair_all 联调唯一任务入口；后续跨模块任务以该目录主控文档和模块卡点文档为准。

## 维护边界

- 跨模块联调任务状态、优先级、执行顺序和端到端验收记录只在 `06-联调收尾/RepairAll跨模块修复计划与进度.md` 维护。
- 模块卡点只在 `06-联调收尾/*模块卡点.md` 维护；模块内部设计、契约和实现细节仍以各模块专项文档为准。
- 契约定义与冻结状态以 `doc/contract/` 为准，不在联调文档中复制定义。
- 历史 Review 与专项记录保留审计价值，但不得覆盖本目录的当前任务状态。
- 移动、新增或删除文档时，必须同步修复相关索引和引用。
