## 4. 文档维护规则

1. 项目目标、架构、模块边界和整体顺序只维护在整体任务规划总览.md。
2. 契约编号、状态、权威位置和阻断范围只维护在跨模块契约目录与冻结状态.md。
3. 契约治理方法只维护在跨模块统一契约制定规范与治理基线.md。
4. 模块字段定义由生产模块专项文档维护；本目录不复制字段表。
5. 任务执行状态由模块自己的 doc/<module>/ 维护；本目录只维护跨模块决议和集成约束。
6. 历史 Review 必须标注基线 SHA 和时间，不得冒充当前代码状态。
7. 任何物理移动/删除前，先检索并修复全仓 Markdown、代码、脚本和 CI 中的路径引用。
