## 1. 当前执行规则

1. 开始任何模块任务前，先读取 PLAT-002 登记簿，确认依赖 CTR 是 `frozen`、`deferred` 还是 `not_applicable`。
2. `frozen` 代表公开语义已冻结，模块必须按权威定义实现；不代表实现、CI、联调或生产验收已完成。
3. `deferred` 项不得提前当作已发布接口使用；只有登记簿所列重新进入条件满足后，才启动定点复核。
4. 模块实现工作只在用户指定的对应模块分支进行；不得在 `feat/design_doc` 或 `integration` 上擅自开发业务代码。
5. 模块任务、当前分支 SHA、测试命令、CI Run 和未完成项由对应模块专项文档维护；本文件不再复制模块任务看板。
6. 跨模块集成由用户确认的治理流程执行；不得因本文历史任务文本自动创建分支、PR 或执行合并。

## 2. A1/A2/A3 与 L1/L2/L3 的区别

- A1/A2/A3 描述模块接入和环境验收的准入级别。
- L1/L2/L3 描述契约定义冻结、实现符合性和真实集成/运行验收阶段。
- 两套口径不能互相替代。特别是 L1 契约冻结不自动把模块提升为 A2/A3，也不意味着所有 L2/L3 工作完成。
- 当前 CTR 状态与冻结范围只以 PLAT-002 登记簿为准；模块接入级别必须根据当前模块证据逐项判定。
