## 1. 验收原则修正：不要求所有分支同时编译

GOV-004 应拆成三个相互独立、按需组合的验收维度：

1. **模块自身验收**：在模块自己的分支和代码范围内完成格式、编译、单测、race、vet、专项测试。某个其他分支失败，不自动使本模块自身验收失败。
2. **公共契约验收**：验证双方公开 DTO、Schema、错误语义、时间/单位/授权边界和契约测试。契约审查可以先于双方完整集成构建；如果缺少真实实现证据，应标记为“设计已审/实现待验证”，不能标记冻结。
3. **跨模块集成验收**：只有在验证组合根、真实 Adapter、跨模块调用、Migration 装配或端到端行为时，才要求相关模块在同一集成基线上共同构建。依赖模块的编译失败只阻断该集成用例，不回溯否定其他模块已经通过的独立验收。

因此，GOV-004 不应使用“Data/News/Platform 三个分支必须同时全绿”作为总门槛。总状态应分别列出模块验收、契约冻结和集成验收。一个模块可以独立验收通过，而整体公共契约仍因字段/语义未冻结保持 NO-GO。

### 1.1 状态词汇

| 状态 | 含义 |
|---|---|
| PASS | 对应范围和当前 SHA 的验收证据完整且通过 |
| FAIL | 对应范围和当前 SHA 的验收实际失败 |
| PENDING | Workflow/测试尚未结束，不能提前判断 |
| BLOCKED | 本项需要的具体依赖或证据不可用 |
| NOT RUN | 没有执行该项，不得推断通过 |
| DESIGN ONLY | 设计已评审，但没有实现/运行证据 |
| N/A | 当前阶段不适用，需说明原因 |

禁止把一个分支的 FAIL 自动复制成其他分支的 FAIL；也禁止把单独包测试 PASS 扩大成生产集成 PASS。

## 3. News N6 最新代码核查

### 3.1 已实现能力

最新树和源码确认：

- `internal/news/domain` 已有 Observation、NewsItemVersion、SecurityIdentityRecord、IndustryClassificationRecord、RelationAssertion/RelationEvidence 等领域对象。
- Observation、NewsItemVersion、SecurityIdentityRecord、IndustryClassificationRecord、RelationAssertion 均保存系统观察时间字段。
- `app.IngestCandidate` 通过 `IdentityRepository` / `IdentityTransaction` 端口执行身份凭据查询、创建 News Item、保存凭据和追加 Observation。
- `app.ApplyResearchUpdate` 通过 `ResearchUpdateRepository` / `ResearchUpdateTransaction` 端口追加版本和关系断言，并检查 Observation/Version 归属。
- 当前提交区分 ProviderItemID 与 SourceItemID，Feed GUID/ID 映射为 SourceItemID，Feed author 与 Publisher 身份分离。这是来源身份语义改进。
- `domain.EvaluateSourceCollectionPolicy` 和 `EvaluateProviderOutputPolicy` 分开评估来源与 Provider 输出权限。

### 3.2 N6 仍未实现的关键能力

源码核查未发现下列生产能力：

- 没有 `ResearchEvidenceQuery`、`GetEvidence`、`ListEvidence` Application 只读 Facade 或对应公开 DTO。
- 现有 Repository 是写入用例依赖的接口；当前树中没有 News 生产 Repository Adapter、SQL Migration 或数据库持久化实现。
- Security/Industry Resolver 只按业务有效时间解析，没有 `system_as_of` 参数；`ResolveCurrentRelations` 只解析当前关系。
- 没有统一先按系统知识时间过滤 Observation、Version、Identity、Classification、Relation，再按业务有效时间解析的查询闭环。
- `PolicyDecision` 只有 Allowed、ReasonCode、MaxRetention，没有不可变决策 ID、策略版本/快照引用、评估时间和快照哈希。
- 没有固定快照、稳定排序和防篡改 Cursor 的分页实现。
- `SearchCandidates` 仍明确不持久化、不缓存。

因此，News 不是“完全没有 Repository 契约”，而是**已有写入 Repository Port，但缺生产 Adapter/Migration；同时缺面向 Research 的只读查询 Facade 和 PIT/授权/分页闭环**。这一区分应取代笼统的“Repository 未实现”描述。
