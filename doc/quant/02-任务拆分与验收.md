## 执行批次

1. P0：QNT-001~003。
2. P1：QNT-004~010；市场/行业/个股按契约并行，策略和回测后置。
3. P2：QNT-011/012，等待足够历史样本和回测验收。
4. 存储可与对应领域能力并行设计；QNT-013 不得修改根 Migration 注册入口。

## 完成门禁

- 单测覆盖公式、窗口边界、缺失/异常、单位、精度和时区。
- 固定样本可重复运行，差异有解释。
- PIT/复权有独立测试。
- 回测交易制度和成本假设有边界测试。
- 真实数据验收记录 Provider、证券、日期、样本数、快照和质量。
- CI 精确关联当前 SHA；Mock/Fixture/构建通过不能代替真实数据验收。

## 依赖分层校正（GOV-004 / GOV-005）

| 任务 | 领域开发依赖 | Adapter/集成依赖 | 调整说明 |
|---|---|---|---|
| QNT-001 | 公共基础语义和首批 Quant DTO 评审 | Data Snapshot Adapter 字段映射 | 不要求 Data 当前分支构建通过；先用固定 Fixture 定义输入边界 |
| QNT-002 | QNT-001 中 Indicator 输入/参数子契约 | Data 日 K Adapter | 固定样本可独立验收，不等待 Data Provider |
| QNT-003 | QNT-001 中 Factor 上下文/输出子契约 | Data Universe/分类数据 Adapter | 不强制依赖 QNT-002；只有具体因子复用 Indicator 时才形成组合依赖 |
| QNT-004 | QNT-002/003 的稳定输出 | 多周期 Data Adapter | 允许使用 Fixture |
| QNT-005/006/007 | 对应 Market/Sector/Security 输入 DTO | Data 对应 API Adapter | 分别独立，不应互相串行等待 |
| QNT-008 | 所需 Trend/Market/Industry/Stock 结果契约 | Researchflow 调用接入 | 领域策略可先基于固定结果 Fixture |
| QNT-009 | QNT-008 的版本化策略定义 | PIT 历史行情/公司行动真实数据 | 真实数据验收单独阻断，不阻断策略模型设计 |
| QNT-010 | 风险规则与输入质量语义 | 真实数据与交易状态 Adapter | 硬门禁纯逻辑先行；输入 unknown 必须 fail-closed |
| QNT-011/012 | 已冻结的回测/风险结果结构 | 足量历史样本和持久化 | 统计效果验收不能用小样本或 Mock 代替 |
| QNT-013 | Repository Port、结果身份/版本和事务边界 | Platform Storage、根 Migration 组合入口 | Repository/Schema 可与领域开发并行设计；真实 DB 集成和根注册归 L3 |

### 本模块可独立开工边界

- QNT-001~003 可先使用固定输入样本和内存实现完成领域算法及契约测试。
- QNT-003 与 QNT-002 不建立强制串行依赖；Factor 可以消费标准化输入序列，不必依赖 Indicator Engine。
- Data OpenAPI/Go DTO 修复只影响对应 Data Adapter 字段，不阻断 Quant Domain。
- QNT-013 拆分为 Repository Port/Schema 设计、模块 Repository 实现、真实 Storage/根 Migration 接入三个验收项；不得要求所有 Quant 能力完成后才开始存储设计。
