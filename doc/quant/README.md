## 文档维护规则

1. 任务状态只维护在模块总任务规划和进度中；当前任务文档只描述唯一正在执行的任务。
2. 历史文档追加完整执行证据，不随任务切换删除。
3. 项目级契约编号、冻结状态和跨模块决议以 `doc/contract/` 为准。
4. 本目录不保留已经迁入任务历史的重复阶段说明；机器 Schema/Golden 不作为普通说明文档清理。
