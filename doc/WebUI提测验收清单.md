# WebUI 功能提测与集中验收清单

更新日期：2026-10-30
目标分支：feat/webui-market-data-console
验收策略：先完成页面和接口闭环开发，再集中进行一次完整浏览器验收；开发期间不反复进行零碎浏览器检查。

## 1. 本批次范围

- 自选股辅助字段显示顺序与显隐。
- 工作区 JSON 页面内导入预览、替换/合并/取消。
- 设置中心 10 个分组整体检查。
- 数据层 API 与页面接入文档更新。
- 文档统一迁移至根目录 doc/，清理历史计划、重复交接记录和过时状态日志。

## 2. 自选股验收

- [ ] 5 个辅助字段均可单独显示/隐藏。
- [ ] 上移/下移改变字段顺序，桌面与移动端顺序一致。
- [ ] 字段顺序和显示状态刷新页面后保留。
- [ ] 导出 JSON 后包含 watchlistDisplayOrder。
- [ ] 导入旧版 v1/v2 JSON 时兼容，缺失顺序字段回退默认顺序。
- [ ] 非法字段、重复字段、缺失字段或未知字段顺序被拒绝。
- [ ] 代码/名称和操作按钮始终保留，不受辅助字段配置影响。
- [ ] 排序字段、方向与过滤不互相覆盖。

## 3. 工作区导入验收

- [ ] 选择文件后先展示页面内预览，不立即写入。
- [ ] 展示文件自选股/任务数量、与当前清单的冲突数量、当前本地清单数量。
- [ ] 明确说明主题、偏好、API 路径将导入，当前行情 API Key 保留。
- [ ] 替换导入完整替换两组清单。
- [ ] 合并导入按证券代码和任务标识去重，导入项覆盖冲突项。
- [ ] 本地清单不可读取/格式异常时禁用合并。
- [ ] 合并超过自选股 50 条或最近任务 10 条上限时拒绝写入。
- [ ] 取消、Esc、关闭按钮均不修改现有数据。
- [ ] 存储写入后逐项回读确认；失败时验证回滚结果。
- [ ] 导入后主题、设置控件、自选股、研究页、最近任务刷新一致。
- [ ] 导入不覆盖当前 API Key，不导入完整分析报告。

## 4. 设置中心整体验收

- [ ] 10 个分组导航可定位，折叠/展开、搜索和滚动高亮正常。
- [ ] 显示偏好：主题、涨跌颜色、价格/百分比精度、数字单位、自选字段设置均可保存。
- [ ] 连接与服务：路径校验、已保存配置检查、草稿检查、保存、清除本地连接配置正常。
- [ ] 行情 API Key 明文显示/隐藏正常；默认不回显已保存值。
- [ ] 行情 API Key 与分析服务连接配置/管理员登录态保持概念隔离。
- [ ] 浏览器本地数据：导入/导出、容量限制、冲突处理、错误提示和存储边界说明正常。
- [ ] 基础设置：日 K 默认条数与复权方式联动新查询；不影响历史任务/报告。
- [ ] 数据源管理：能力声明与实时健康区分；不允许前端假保存 Provider 密钥。
- [ ] AI、通知、调度、选股和安全配置对未接入服务端能力明确标注。
- [ ] 所有设置均明确存储范围；不存在 localStorage 假装服务器配置已保存。
- [ ] 桌面双列和窄屏单列布局无溢出、遮挡或不可达控件。
- [ ] 键盘可操作，焦点可见，弹窗可通过 Esc/关闭按钮取消。

## 6. 自动化/静态检查建议（集中执行）

1. npm test：模块单测与静态回归。
2. npm run check：格式/静态检查。
3. HTML ID 唯一性、JS 模块语法、无外部非预期请求。
4. 运行 WebUI 本地服务，使用真实测试 API 或明确的失败响应验证，不注入假行情。
5. Playwright/浏览器检查桌面、平板、手机视口；检查 Console、Network、无障碍焦点和截图。
6. 对工作区导入进行 v1/v2/v3 兼容、替换、合并、冲突、超限、损坏文件和 localStorage quota 测试。
7. 集中检查通过后形成一次提测结论；任何失败按功能批次修复，不拆成反复的小型验收轮次。
