# Data 模块文档索引

本目录维护 Market Data 模块的唯一任务规划、执行状态、历史证据、依赖、架构和专项说明。

## 1. 唯一任务入口

- [模块总任务规划和进度](./模块总任务规划和进度.md)：任务编号、优先级、状态和关闭条件的唯一权威来源。
- [当前任务状态和进度](./当前任务状态和进度.md)：唯一当前执行任务。
- [任务历史](./任务历史/各个子任务完成状态.md)：原始任务路线、历史 SHA、Run、真实样本和执行记录。

## 2. 规范目录

- [依赖](./依赖/)：跨模块依赖、Owner 和责任边界。
- [架构](./架构/)：Provider/数据域能力边界、质量诊断架构。
- [说明](./说明/)：文档维护与验收口径。
- [其他](./其他/)：专项资料索引。

## 3. 专项证据与契约

以下目录保留已有专项文件，不因目录规范调整而丢弃真实证据：

- [字段质量与诊断](./quality/)
- [真实数据验收](./acceptance/)
- [Provider 迁移与 Python/Go 对照](./provider-migration/)
- [模块化单体迁移记录](./migration/MarketData模块化单体迁移计划与进度.md)
- Data HTTP/OpenAPI 契约、字段 Schema、样例与 Golden：以仓库中现存契约文件为准，不在本 README 虚构目录入口。

## 4. 维护规则

1. 总规划是任务状态唯一权威来源；当前任务文档只能有一个。
2. 已完成任务完整归档到任务历史；历史记录不随任务切换删除。
3. 新任务必须先进入总规划并取得唯一编号。
4. 任务完成必须有实际验收依据，不能仅凭代码提交。
5. Provider 真实数据验收与工程迁移验收分开记录。
6. README 只提供索引，不维护第二份任务状态。
