## 统一状态语义

- **通过**：对应检查项有充分、可比的证据且满足规则。
- **降级**：存在明确限制或 warning，但结果仍可按声明的限制安全使用。
- **失败**：真实违反契约、数据错误或依赖执行失败。
- **不可比较**：缺少同口径、参考时间、样本或来源证据，不能作通过/失败结论。
- **未执行/跳过**：没有发起真实请求，或因未配置/不支持而未运行；不得冒充通过。

本索引不复制 Validator 规则，也不另建诊断框架。
