# Data 跨模块依赖与责任边界

更新时间：2026-11-18  
维护分支：`feat/data`

## 1. 责任边界

| 能力 | Data 责任 | 外部责任方 | 约束 |
|---|---|---|---|
| Provider 协议、原始字段解析 | Data | 无 | Provider 行为和领域语义归 Data |
| 标准化、质量规则、PIT、Freshness | Data | Platform 提供通用诊断运行基础 | 不将领域规则移交 Platform |
| Repository、Data 表结构、Migration 内容 | Data | Server 负责总注册与执行 | 不在 Data 重建全局 Migration Runner/Lock |
| HTTP Client、Fault、Diagnostics 基础设施 | 使用公共能力 | Platform | 不重复实现公共原语 |
| DB/Redis 连接池、配置聚合、Secret 装配 | 接收注入并定义领域配置 | Server | Data 不创建 Root 级共享资源 |
| Root 路由、认证、Readiness、生命周期 | 提供 Handler/Diagnostics/MigrationRunner | Server | Data 不实现组合根 |
| TCP Provider 出站 | 提供可注入 DialContext | Server；是否公共化由 Platform 评估 | 没有多模块真实消费者前不新增泛化接口 |
| Research/Quant/Researchflow 数据消费 | 提供公开 Application Port | 对应消费者 | 消费者不得依赖 Provider、Repository、SQL 或内部 Model |

## 2. 已有公共能力与禁止重复建设

- Platform `storage.ApplyMigrations` 已提供 namespace 级 Migration Lock；Data Store.Migrate 已调用。
- Platform HTTP BoundDoer 已存在；Data Provider 通过依赖注入使用，不自建平行公共 HTTP Client。
- Platform Fault、Diagnostics、Time 等能力按项目契约使用。
- Server 是唯一组合根，负责共享 DB/Redis、配置/Secret、路由、Migration Registry、Readiness 和 Lifecycle。

- Data 的 Go Module 代码位于根 `internal/marketdata/**`。
- Data Application Port、Bootstrap Module、InProcessHandler、Diagnostics 和 MigrationRunner 已存在。
- `repair_all` 已将 Data 迁入根 Go Module，并由 Root Server 统一注册 Data Migration、注入共享资源、挂载 InProcessHandler 和 Readiness；RA009 单入口代码验收精确 SHA `1e916220a8784ae840132ce0cec3b3654c6b9655` 的 Integration CI Run `44482650366` 全项 success。
- 上述结论只代表 `repair_all` 聚合分支代码验收，不代表 `feat/data` / `feat/server` 已同步，也不代表目标环境 M6 生产部署验收完成。
- BaoStock/Pytdx TCP DialContext 由 Data Module 暴露注入点；Root 受控实现按现有装配路径管理，不另建公共 TCP BoundDialer，除非证明存在跨模块真实消费者。

## 4. 依赖变更准入

新增依赖或公共接口前，必须同时说明：
1. 真实调用方和调用场景；
2. 当前公共能力为什么不能满足；
3. 所有权、超时、取消和错误语义；
4. 测试与验收证据；
5. 是否已有其他模块消费者。

没有真实消费者时，不新增预留接口。


## 5. DATA-CTR-005 / DATA-CTR-007 解阻入口

- 当前 Data Application Port 的 DailyBar 与 Provider Model 使用 float64；数据库 DECIMAL 列定义不能证明 Provider 原始精度，也不能恢复 Provider 入口已经丢失的十进制词法值。
- DATA-CTR-005 DailyBars Decimal v2 是 DATA-CTR-007 内容寻址 Snapshot 的前置；DEC-PLAT-002-020 已确定 Data 提供不可变 Manifest/行情事实、Quant 消费输入质量、Research 引用 Snapshot 并保留 Provider 版本/定位。
- 详细的当前实现证据、推荐 DTO/Snapshot/授权边界及 D1-D7 验收顺序见 [DATA-CTR-005/007 解阻方案](./02-DATA-CTR-005与007解阻方案.md)。
- 本方案不将 deferred 契约擅自改为 frozen；先完成 D1 原始字段证据盘点，再按证据形成 v2 DTO/Schema/Golden，禁止从 float64 回转字符串伪造精度。
