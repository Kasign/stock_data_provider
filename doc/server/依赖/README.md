# Server 依赖文档索引

本目录记录 Server 组合根对各模块、Platform、部署环境的依赖条件和责任边界，不替代项目级契约，也不定义模块私有接口。

## 文档

- [模块装配依赖矩阵](./01-模块装配依赖矩阵.md)：记录各模块当前可供 Server 消费的公开能力、Root 接入状态和准入条件。
- [Data M3/M4 前置核验](./02-Data-M3-M4前置核验.md)：记录 Data Module 接入 Server 前必须解决的 Migration、受控出站、Diagnostics、路由和 Lifecycle 问题。

## 维护规则

1. 依赖项必须有明确提供方、消费方、调用场景和当前证据。
2. 依赖能力已经由 Platform 或模块提供时，Server 只做装配，不复制实现。
3. 依赖未就绪时标记 BLOCKED/DEFERRED/NOT_COMPARABLE，不以空实现或 Mock 冒充通过。
4. 新增依赖若需要新接口，先说明真实消费者、调用场景、字段来源和语义，再决定接口归属。
5. 依赖状态变化后同步模块总规划和当前任务；历史证据只追加，不覆盖。
