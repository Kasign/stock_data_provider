### 1. 任务边界

仅处理 internal/server/** 和 doc/server/**。

Server 负责 Root Bootstrap、公开 Module 构造、共享资源注入、受控 Egress 注入、Migration 注册调度、Readiness/Lifecycle 接入和 HTTP Handler 挂载。Data 领域 Migration 定义、SQL、checksum 规则及 Provider 实现由 Data Owner 提供；公共只读 Migration checksum 能力由 Platform 提供。

不得在 Server 复制 Data Migration SQL、checksum 算法、Provider 或 Platform 公共能力。不得因迁移收口缺口重做已经通过的 Module Bootstrap、HTTP 路由和生命周期装配。
