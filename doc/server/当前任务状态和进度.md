## 当前唯一任务

**SRV-003：HTTP 宿主/认证/Fault 映射**

状态：IN_PROGRESS

### 1. 任务边界

仅处理 `internal/server/**` 和 `doc/server/**`。

本任务验证 Server Root 的 HTTP 宿主如何将真实 Data `InProcessHandler` 挂载到统一路由、认证和 Middleware 下。不得修改 `internal/marketdata/**`，不得复制 Data Handler、Fault、Request ID 或 Platform Router 能力。

不调用真实 Provider，不新增业务 API，不以确定性校验响应冒充真实市场数据验收。

### 2. 已有能力（不重复开发）

- `router.go` 已将 Data OpenAPI 路径前缀挂载到 `marketDataModule.InProcessHandler()`，并使用 Platform Router 的 Owner Bearer RoutePolicy。
- `router_test.go` 已覆盖显式路由策略，但 Data Handler 使用 Stub，未验证真实 Module Handler 的 Root 挂载路径。
- `http_middleware_test.go` 已覆盖请求体大小限制、Request ID 生成、并发限制、Platform Fault 状态码和错误信封。
- `internal/marketdata/httpapi` 已有自身 Handler/OpenAPI/Contract 测试，但不等同于 Server Root 组合后的 HTTP 验收。
- SRV-001 API 角色真实 Root 进程、MariaDB/Redis、Owner Readiness、SIGTERM 已通过 Run 44312706873。

### 3. 本任务验收内容

1. 使用真实 Server API Root 进程和真实 Data `InProcessHandler`。
2. 未认证访问 Data 路由必须返回 401。
3. Owner Bearer 访问确定性非法 Symbol 路径，必须进入 Data Handler 并返回稳定的 Validation Fault；该路径应在 Provider 调用前完成校验。
4. Root 生成的 `X-Request-ID` 必须存在；不能信任调用方传入的伪造 Request ID。
5. 对 Data Probe 路径发送超过配置上限的请求体，Root 必须返回 413 和稳定错误码。
6. Data 路由通过 Root Owner Bearer 即可访问，不要求 WebUI 提供 Data API Key。
7. 精确 SHA 的 Server package tests、Race、真实 MariaDB/Redis、镜像构建和容器 Bootstrap 全部通过。
