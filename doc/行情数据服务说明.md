# 行情数据服务说明

更新日期：2026-10-30

## 1. 服务职责

Go 行情数据服务负责 A 股实时行情、日 K、证券搜索/档案、财务、公告、资金流、筹码分布、板块、指数、市场宽度、涨跌停池、龙虎榜、交易日历和交易时段等数据域。

接口定义以 services/market-data/openapi.yaml 为唯一权威来源；本文只说明服务边界和运行注意事项。

## 2. Provider 与能力

Provider 的启用状态由服务端配置控制。Provider 注册清单通过 GET /api/v1/data-sources 返回，字段是静态能力声明，不代表实时请求成功。某个能力是否可用，还需结合接口实际响应、quality_status、quality_reasons 和源端时间判断。

当前能力域包括：实时行情、日 K、证券档案、证券搜索、行业/概念排行、核心指数、市场宽度、涨跌停池、龙虎榜、交易日历、财务、估值、所属板块、公告、筹码分布、个股资金流和人气榜。

## 3. 运行诊断

GET /api/v1/data-sources/diagnostics 返回真实行情和日 K 请求形成的进程内熔断器观测：
- 仅覆盖 quote 与 daily_bars。
- 不主动探测所有 Provider。
- 进程重启后历史计数重置。
- 当前 WebUI 数据中心尚未接入该接口，仍展示健康检查和 Provider 静态能力。

## 4. 统一数据规则

- 价格 CNY/股，成交量股，成交额 CNY。
- 百分比使用百分点表达。
- 区分源端时间、采集时间、标准化时间和系统观察时间。
- unknown 不等于 0；空列表不自动代表无事件。
- 所有接口参数、Schema、错误状态与安全要求以 OpenAPI 为准。

## 5. 相关路径

- OpenAPI：services/market-data/openapi.yaml
- HTTP 路由：services/market-data/internal/httpapi/server.go
- Provider/业务逻辑：services/market-data/internal/provider、services/market-data/internal/service
- 环境变量示例：services/market-data/.env.example
- 容器构建：services/market-data/Dockerfile
