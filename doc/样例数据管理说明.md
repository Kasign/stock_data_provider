# 黄金样例数据说明

黄金样例用于验证 Python 与 Go 迁移前后的字段、单位、时间、质量状态和确定性计算。样例必须脱敏、可追溯、可重复运行，不能将样例响应伪装成实时供应商数据。

## 1. 当前状态

当前仓库尚未建立完整的 Python/Go 双侧固定样本集。本文件定义样例组织和准入标准；没有真实样本文件时，不得宣称已经完成字段级对账。

## 2. 推荐目录

- `stock/`：证券代码、日 K、实时行情、筹码/财务数据块及原 Python 个股分析结果。
- `market/`：市场区域、市场概览、新闻条目及原 Python 市场复盘结果。
- `provider/`：按 Provider 保存脱敏原始响应，保留采集时间和接口版本。
- `expected/`：经过 Review 确认的 Go 标准化结果、质量状态及 API 契约断言。
- `manifest/`：样例来源、采集环境、代码版本、证券范围、日期、复权口径和文件校验值。

## 3. 最低样本覆盖

1. 沪深主板、创业板、科创板、北交所。
2. 正常交易日、停牌日、非交易日。
3. 除权除息前后和不同复权口径。
4. 成交量/成交额缺失、真实零值、异常数量级。
5. 重复、乱序、越界日期和分页不完整。
6. 新股、ST/风险警示、退市及涨跌幅特殊阶段。
7. 财务报告期、公告时间、修订版本差异。
8. 上游空响应、错误码、超时、限流和权限不足。

## 4. 每个样例必须记录

- 样例 ID、数据域、Provider 和接口版本；
- 证券代码/市场、交易日、观察时点；
- Python 上游仓库及固定 commit；
- 原始字段和 Go 标准字段映射；
- 原始单位、标准单位、转换依据；
- adjustment_basis、adjustment_method；
- provider_time、report_date、announcement_time、available_at、fetched_at；
- quality_status、quality_reasons、fallback 来源；
- 脱敏方式、生成时间和内容 SHA-256；
- 差异结论及 Review 记录。

## 5. 对账规则

- Python 与 Go 必须使用相同证券、日期、观察时点和可比复权口径。
- 对数值比较前统一单位、时区和精度；不同复权算法不能直接按绝对价格判等。
- null、0、空数组、无记录和 unknown 必须分别比较。
- 字段缺失或单位无法证明时，保留 unknown/null/degraded，不允许猜测补齐。
- 更新 expected 基准必须说明变更原因、生成代码版本和差异，并经过 Review。
- Go 质量门禁、标准 shares/CNY 单位和复权语义是迁移保护项，不得为了匹配旧 Python 的不确定行为而删除。
