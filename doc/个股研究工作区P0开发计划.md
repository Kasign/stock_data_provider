# 个股研究工作区 P0 开发计划

更新日期：2026-11-03
目标分支：`feat/webui-market-data-console`
范围：仅 WebUI 与 `doc/`；不修改 Go、Provider、数据库、OpenAPI 服务端实现或部署配置。

## 1. 目标闭环

市场总览/全市场分页/自选股发现标的 → 进入个股研究 → 核验行情与资料 → 发起分析任务 → 查看真实 Run 结果 → 归档报告/保存研究笔记。

所有行情和分析结论必须来自真实服务端回包。浏览器本地笔记、最近任务引用和报告归档必须明确标记本地边界，不得冒充服务端历史。

## 2. 当前基线

- 个股研究页已具备行情摘要、日 K、MA/RSI/MACD、上市档案、行业概念、财务、估值、个股资金流、筹码、公告、研究笔记与 Run 报告归档。
- 研究页已有发起分析任务入口；最近任务仍是浏览器本地最多 10 条引用。
- 全市场分页行情已支持真实分页、质量信息、行情详情和直达深度研究入口。
- 请求取消、标的切换清理、空数据/错误/stale/null 处理已具备专项测试；本阶段不重复实现。
- 服务端任务历史分页 API 仍缺失；不能在 WebUI 伪造完整历史。

## 4. 跨分支依赖与明确不做

- 服务端任务历史分页 API 尚未提供：保持本地最近 10 条引用说明，不自行构造服务端列表。
- 全市场筛选/服务端扫描、告警 CRUD、通知渠道和 AI 问股 API 属于后端缺口，不在本轮 WebUI 伪造。
- Provider 真实数据质量、估值/财务/资金流/筹码黄金样例对账需要部署环境验证。
- 不引入 React，不使用演示行情，不在本分支修改服务端或部署文件。
