## 6. Review 检查顺序

1. Provider Port、DTO、ProviderConfig、CapabilityState 的字段来源、语义和校验。
2. Responses JSON 请求映射、响应解析、未知 output item、错误和 Usage。
3. Responses SSE 事件顺序、sequence、终态、EOF、断连和部分响应语义。
4. Structured Output Schema 编译、strict 子集和能力门禁。
5. Context deadline、取消、超时、限流提示、Body 所有权和资源上限。
6. Secret 脱敏、Request ID、诊断字段和 Platform Fault 映射。
7. 对照 LLM-CTR-001/002/003 与 Platform/Server/Researchflow 公开契约，记录消费者接入约束。
