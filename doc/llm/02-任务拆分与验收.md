# LLM 任务拆分与验收

所有任务初始完成：否。先核实现有独立模型服务协议，不预建多模型复杂路由。

| 编号 | 优先级 | 任务 | 依赖 | 验收 |
|---|---|---|---|---|
| LLM-001 | P0 | 现有模型服务协议盘点 | GOV-001/004 | URL、认证、请求/响应、流式、超时和错误行为 |
| LLM-002 | P0 | Provider/Adapter 接口 | LLM-001、Platform HTTP | 不依赖 Researchflow 或具体业务模型 |
| LLM-003 | P1 | 超时/限流/错误/重试 | LLM-002 | deadline、错误分类、有限重试和取消 |
| LLM-004 | P1 | 结构化输出支持 | LLM-002 | 非法 JSON、截断、Schema 和引用缺失 |
| LLM-005 | P1 | 流式响应适配 | LLM-001/002 | 事件顺序、结束状态、断连和取消 |
| LLM-006 | P1 | 用量和调用元数据 | LLM-002 | 模型/参数/耗时/用量/错误可追踪且不泄密 |
| LLM-007 | P1 | 脱敏和资源限制 | LLM-002/003 | Secret 不入日志、输入输出大小受限 |
| LLM-008 | P2 | 多模型路由/降级 | 真实需求评审 | 明确场景、策略和验收后才实施 |

## 验收门禁
- 与现有模型服务完成真实协议调用，不只用 Mock。
- 超时、取消、限流、错误分类和 Schema 校验覆盖。
- 模型工具调用只作为待校验请求，不由 Adapter 执行。
- 不把自由文本当业务事实；不保存完整敏感 Prompt。
