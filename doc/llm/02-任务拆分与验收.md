## Responses JSON Adapter 首批实现（2026-11-06）

- 新增 MapResponsesRequest：映射 model/instructions/input/max_output_tokens、可选 sampling/reasoning、text.format=json_schema、function tools 和默认 tool_choice=none；不序列化 provider/request/correlation/deadline/system_as_of 等应用层元数据。
- 新增 ParseResponsesResponse：识别 completed/incomplete/failed；按顺序归一化 message、refusal、function_call 和 unknown item；未知 item/content 只保留受限 wire type，不保留任意未知正文。
- Usage 保留上游 nullable 字段；total_tokens 上游优先，缺失时仅在非负且无 int64 溢出时派生；缺失 Usage 不补 0。
- Structured Output 在 completed 后执行本地 Draft 2020-12 Schema 校验，只有通过后才填充 structured_json；不匹配返回 schema_validation_failed。
- 新增首批 Mapper/Parser 单测，覆盖字段映射、状态、工具调用意图、未知类型、Usage 和 Schema 校验。当前仍未执行 gofmt/go test，不能标记测试通过。
