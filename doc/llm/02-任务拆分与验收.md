## LLM-003 重试职责边界

- LLM Provider/Adapter 单次调用，不在模块内部自动重试；不得在 Generate 或未来 Stream 中隐藏重放请求。
- LLM 负责将限流、过载、超时和上游临时错误归一化为稳定错误类型，并提供 `retryable`、`retry_after_seconds` 等提示。
- 是否重试、最大次数、退避、调用预算、幂等性和任务取消由上层调用编排负责；当前由 Researchflow/Server 组合层依据项目契约落实。
- 对非幂等或可能产生重复计费的模型请求，上层必须显式决定是否允许重试；LLM 不推断业务幂等性。
- 本边界避免 LLM 与 Researchflow 重复建设重试策略，也避免 Adapter 在调用方不可见的情况下重复产生模型费用。

## 验收门禁
- 与现有模型服务完成真实协议调用，不只用 Mock。
- 超时、取消、限流、错误分类和 Schema 校验覆盖。
- 模型工具调用只作为待校验请求，不由 Adapter 执行。
- 不把自由文本当业务事实；不保存完整敏感 Prompt。

## LLM-002-E 纯 Responses SSE Parser（2026-11-06）

- 新增 ParseResponsesSSE([]byte, ModelRequest, Clock, callback)，只解析有界内存字节，不创建 HTTP Client、不读取网络流；真实网络 Stream 仍等待 Platform 受控流式传输能力。
- 支持 SSE event/data、多 data 行、CRLF、注释行、EOF pending event；事件类型必须与 JSON data.type 一致。
