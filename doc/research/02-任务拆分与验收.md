# Research 任务拆分与验收

所有任务初始完成：否。

| 编号 | 优先级 | 任务 | 依赖 | 验收 |
|---|---|---|---|---|
| RSC-001 | P0 | Context 模型 | GOV-003/004 | 分区、时间、来源、质量、版本和权限范围 |
| RSC-002 | P0 | Evidence 模型 | GOV-003/004、News 契约 | fact/reported_fact/inference/hypothesis/unknown 和正反证据 |
| RSC-003 | P1 | Event 归并与生命周期 | RSC-002、News | 多来源归并、版本、时间和状态变化可追溯 |
| RSC-004 | P1 | 实体关联和影响路径 | RSC-003、Data Security/Industry | 证券/行业/产业链关联有依据和置信边界 |
| RSC-005 | P1 | Claim/Hypothesis | RSC-001/002 | 支持/反证、验证方法、预期观察和失效条件 |
| RSC-006 | P2 | Scenario 语义模型 | RSC-005、Quant Evaluation | 条件、路径、证据、失效条件和概率引用 |
| RSC-007 | P1 | Repository/版本存储 | RSC-001~006、Platform Storage | 版本追加、幂等、事务和历史引用 |

## 验收门禁
- Evidence 有来源引用、时间语义、版本和类型。
- 事实和推断不得混存或静默升级。
- Event 合并/拆分和生命周期变化可回溯。
- 实体关联不能仅凭 LLM 自由生成。
- Hypothesis 可验证、可证伪。
- Scenario 概率引用 Quant；无样本时为 unknown。
- 不修改 News 原文表和根 Migration 注册入口。

## 依赖分层校正（GOV-004 / GOV-005）

| 任务 | 领域开发依赖 | Adapter/集成依赖 | 调整说明 |
|---|---|---|---|
| RSC-001 | Context 最小 DTO 和公共时间/质量语义 | 无 | 可独立使用内存 Repository/Fixture |
| RSC-002 | Evidence 类型、来源引用、AuthorizationRef 目标结构 | News Research Evidence Query 生产 Adapter | 不等待 News Facade/Repository 实现；不得绕过授权读取真实正文 |
| RSC-003 | RSC-002 Evidence 引用和版本规则 | News 多来源事实查询 | Event 生命周期可先用 Fixture 验收 |
| RSC-004 | 已定义的 Security/Industry 引用 | Data Security/Industry Adapter | 不要求 Data 生产服务先完成 |
| RSC-005 | RSC-001/002 | Researchflow 编排接入 | Hypothesis Domain 独立开发 |
| RSC-006 | RSC-005 和 Quant Scenario 数值引用契约 | Quant Evaluation 真实结果接入 | 语义结构可先用 unknown/Fixture，禁止自行生成概率 |
| RSC-007 | 首批实体和版本策略 | Platform Storage/根 Migration 集成 | Repository Port 和 Schema 可提前设计；真实 DB 验收属于 L3 |
| RSC-008 | Research 质量规则 | Platform Diagnostics Adapter | 领域诊断规则不依赖 Platform 生产接入完成 |

### 本模块可独立开工边界

- RSC-001/002 可先完成领域对象、应用层用例、内存实现和契约测试。
- News 的只读查询、知识时间过滤、授权决策快照和稳定分页未完成时，Research 不得把本地 Fixture 验收描述为真实证据接入通过。
- Research 不复制 News 原文、不自行判断来源授权、不把来源的当前授权等同于历史授权。
- Repository/Migration 的真实接入与 Research Domain 完成度分别验收。
