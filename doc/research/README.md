## 维护规则

1. 总体任务只写入模块总任务规划；当前执行状态只写入当前任务状态文件。
2. README 只做索引，不复制任务状态表。
3. 已完成子任务的证据写入任务历史，保留当时的分支、SHA、Run、测试范围和验收边界。
4. 项目级契约状态以 `doc/contract/` 为准；跨模块生产装配以 Server/Integration 的实际代码和精确 CI 证据为准。
5. 历史文档中的旧 SHA、旧分支名和旧待办仅作历史记录，不得当作当前状态。
6. 暂无独立依赖说明文档；跨模块依赖清单和进入条件统一维护在模块总任务规划，避免出现重复权威。
