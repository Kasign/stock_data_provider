# Research 研究领域模型与证据体系

## 1. 目标与边界

Research 将 Data/News/Quant 提供的可追溯输入组织为事实、证据、事件、假设和情景。它不采集新闻、不拥有行情事实、不重算 Quant 指标、不依赖 Researchflow。

## 2. Context

Context 是特定研究问题、as_of 和权限范围下可用的信息集合，按 Market/Industry/Stock/Event/Evidence/Strategy/Risk 分区。记录 context_id/version、as_of、snapshot/source refs、quality_summary、included/omitted sections、omission_reasons 和 builder_version。

Research 定义模型和语义校验；Researchflow 负责单次 Run 的分区选择、排序、Token Budget、裁剪和调用时装配。裁剪不得静默丢失来源、时间、关键反证和风险限制。

## 3. Evidence

Evidence 至少包含 evidence_id/type、claim_ref、source_type/ref/version/trust、published_at/available_at/observed_at/as_of、证券/行业/Event refs、stance（supports/contradicts/neutral）、epistemic_type（fact/reported_fact/inference/hypothesis/unknown）、quality、limitations 和 content_hash。

来源可信度来自明确来源策略，不由 LLM 自行赋值。原文归 News 或原始事实所有者；Research 保存引用、哈希、必要摘要和最小片段。

## 4. Event

Event 是跨多条新闻/公告的同一现实事件，不是 Article 别名。记录事件类型、版本、发生/公开/可用/观察时间、实体关联、来源 Evidence、重复簇、生命周期、影响假设、预期时效、不确定性、反向证据和价格验证引用。

生命周期建议 detected → consolidating → active → materializing → fading → invalidated/closed。事件归并、拆分和状态变化必须保留版本。

研究顺序：事实确认 → 多来源归并 → 实体关联 → 影响路径假设 → 时效/失效条件 → 价格/行业表现验证 → 历史样本比较。价格上涨不能反向证明新闻事实正确。

## 5. Claim / Hypothesis

Claim 是可被证据支持或反驳的陈述；Hypothesis 是带验证方法的研究假设。必须记录范围、as_of、支持/反证、required data、validation method、expected observation、invalidation condition、状态、版本和限制。无验证与失效条件的“看好/利好”不构成合格假设。

## 6. Scenario

Scenario 是条件化未来路径，不是单一目标价。记录基准时点、周期、触发条件、正反证据、预期路径、风险、失效条件、历史样本和 Quant 概率分布引用。数值概率由 Quant 计算；Research 只负责语义和证据。样本不足时返回 qualitative/unknown。

## 7. 事实类型

- fact：有可验证来源和时间的事实。
- reported_fact：来源声称但未独立核验。
- inference：基于事实推导的解释。
- hypothesis：等待验证的研究假设。
- unknown：证据不足，不能判断。

禁止将 inference 静默升级为 fact；历史 Run 必须引用当时的 Event/Evidence 版本。
