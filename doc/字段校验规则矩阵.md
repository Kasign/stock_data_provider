# A 股字段校验规则矩阵

- 目标分支：`feat/full-go-data-providers-api-switch`
- 基线 SHA：`45f58dfa7ac014a1b945fb0e929282b63bb23228`
- 更新日期：2026-11-02
- 关联方案：`doc/字段校验与诊断体系实施方案.md`
- 当前用途：记录现有 Normalize 函数实际执行的规则；“当前行为”不等于最终契约，最终规则必须结合 Provider 字段支持、A 股交易状态和历史兼容确定。

## 1. 状态定义

| 标记 | 含义 |
|---|---|
| 已实现 | 当前 `ValidateQuote` 或 `ValidateAndSortBars` 明确执行 |
| 部分实现 | 有基础检查，但缺少字段级问题、上下文或完整语义 |
| 未覆盖（本函数） | 这两个函数未校验；不代表其他模块一定没有校验 |
| 待确认 | 必须结合 Provider 契约、调用点或业务场景确定 |

严重级别建议：error 表示违反明确字段契约；warning 表示数据可用但质量降级；info 表示 Provider 不支持或仅提示。严重级别不能仅根据当前函数“丢弃记录”这一实现动作机械推断。

## 2. Quote 字段规则

| 字段 | 当前规则 | 当前状态 | 目标规则 / 迁移关注点 |
|---|---|---|---|
| symbol | 必填；必须是规范六位 A 股代码及交易所后缀 | 已实现 | required + 证券主数据校验；保留 BJ 等市场规则 |
| source | 必填 | 已实现 | required；Provider 标识应来自适配器注册信息 |
| quality_status | valid/degraded/stale/unknown；invalid/未知值拒绝 | 已实现 | invalid_enum；缺失和来源质量状态分开诊断 |
| adjustment_basis | none/forward/backward/unknown | 已实现 | invalid_enum；Quote 是否允许 unknown 需按接口契约确认 |
| current_price | 必填、有限且 > 0 | 已实现 | required + invalid_number + out_of_range；停牌/无成交快照条件待确认 |
| open | 必填、有限且 > 0 | 已实现 | 同上；盘中/停牌状态下的可用性需确认 |
| high | 必填、有限且 > 0 | 已实现 | 同上；OHLC 关系单独规则 |
| low | 必填、有限且 > 0 | 已实现 | 同上 |
| prev_close | 必填、有限且 > 0 | 已实现 | 新股首日、特殊无昨收场景需条件化 |
| change | 可缺失；存在时有限；与 current_price-prev_close 误差不超过 0.02 CNY | 已实现 | invalid_number + derived_consistency；容差按源端精度配置 |
| change_percent | 可缺失；存在时有限；与计算值误差不超过 0.15 个百分点 | 已实现 | invalid_number + derived_consistency；明确百分点单位和精度 |
| volume | 必须存在且非负 | 已实现 | required / conditional 需结合停牌和快照状态；单位统一 shares |
| amount | 可缺失；存在时有限且非负 | 已实现 | optional 或 conditional；缺失必须保留 NULL |
| amount_unit | amount 存在时必须 CNY；amount 缺失时当前函数改成 unknown | 已实现 | unit_mismatch；纯 Validator 不修改字段 |
| volume_unit | 必须为 shares | 已实现 | unit_mismatch；Provider 原始单位在 Adapter/Normalize 转换 |
| volume_ratio | 可缺失；存在时有限且非负 | 已实现 | out_of_range；定义负值和特殊状态边界 |
| turnover_rate | 可缺失；存在时有限且非负 | 已实现 | out_of_range；明确百分比单位 |
| OHLC 关系 | low<=high；open/current_price 位于 low/high 区间 | 已实现 | ohlc_relationship；是否需要按停牌/盘中状态调整待确认 |
| amount/volume | 不允许一正一零；两者为正时隐含均价需在 low×0.5 到 high×2 | 已实现 | unit_mismatch / cross_field_consistency；容差与场景需要有明确证据 |

## 3. DailyBar 字段规则

| 字段 / 规则 | 当前规则 | 当前状态 | 目标规则 / 迁移关注点 |
|---|---|---|---|
| 请求 start/end | 非空时必须为严格 YYYY-MM-DD | 已实现 | 请求参数校验应与单条记录 Validator 分离 |
| symbol | 当前由函数参数覆盖每条记录的 symbol，不检查原值 | 部分实现 | 需要先验证 Provider 返回身份；不能静默覆盖错误证券代码 |
| trade_date | 必须为合法日期；start 前过滤；end 后丢弃；同日重复只保留首条 | 部分实现 | invalid_date、duplicate_record；范围过滤不应混入字段合法性 |
| period | 必须为 1d | 已实现 | invalid_enum；当前接口是日 K 专用契约 |
| open/high/low/close | 必须有限、为正，且 OHLC 关系合理 | 已实现 | required、invalid_number、out_of_range、ohlc_relationship |
| volume | 必须存在且非负 | 已实现 | required / conditional 需结合停牌/无成交状态 |
| volume_unit | 必须为 shares | 已实现 | unit_mismatch；明确 Provider 各市场原始单位 |
| amount | 可缺失；存在时有限且非负 | 已实现 | optional / conditional；缺失保留 NULL |
| amount_unit | amount 存在时必须 CNY；缺失时当前函数改为 unknown | 已实现 | unit_mismatch；纯 Validator 不修改字段 |
| amount/volume | 不允许一正一零 | 已实现 | cross_field_consistency；停牌/无成交场景需验证 |
| amount/volume 与 OHLC | 仅 adjustment_basis=none 时检查隐含均价在 low×0.5 到 high×2 | 已实现 | 仅对同一未复权价格基准执行；复权数据不做错误交叉比较 |
| change_percent | 可缺失；存在时必须有限 | 已实现 | invalid_number；单位为百分点 |
| adjustment_basis | 只接受 none/forward/backward | 已实现 | invalid_enum；unknown 不可参与可比分析 |
| source | 缺失时改为 unknown，并把质量设为 unknown | 部分实现 | Provider 身份应由适配器元数据确定；缺失时结构化 warning |
| quality_status | 缺失时设 unknown；只接受 valid/degraded/stale/unknown | 部分实现 | invalid_enum；保留源端质量和本地校验结论的区别 |
| symbol 归属 | 覆盖为请求 symbol | 部分实现 | 必须先检查返回证券身份，防止错证券数据被“修正”为目标证券 |
| 排序 | 最终按日期升序 | 非校验操作 | 保留在 Normalize / 结果整理流程 |
| limit | 超限时保留最新 limit 条 | 非校验操作 | 保留截断提示；不能计作数据质量错误 |
| warnings | 字符串聚合、去重；OHLC 详细上下文最多五条 | 部分实现 | 替换为 FieldIssue；保留问题总数、截断数和 row_index |

### DailyBar 当前函数未检查的字段

以下字段存在于 `model.DailyBar`，但不由当前 `ValidateAndSortBars` 检查：

- is_partial；
- ma5、ma20、ma120、ma250；
- adjustment_method、adjustment_reference_date；
- adjustment_factor_source、adjustment_factor_source_version、adjustment_factor_system_observed_at；

MA 字段是否需要在数据层校验，取决于它们是 Provider 原始输出还是本地计算结果。若为本地计算结果，应验证计算窗口、输入数据覆盖和结果一致性，不能简单套用 Provider 必填规则。

## 4. 必须补充的 A 股上下文

| 场景 | 规则影响 | 当前状态 |
|---|---|---|
| 停牌 | 允许无成交或成交量为零；价格和时间字段应结合停牌状态解释 | 待确认 |
| 新股上市首日 | 可能没有常规 prev_close；涨跌幅限制也可能不同 | 待确认 |
| 除权除息 | 前收盘价、涨跌幅和复权序列可能有特殊口径 | 待确认 |
| 非交易日 | 快照可能是上一交易日；不能仅凭日期较旧判 invalid | 待确认 |
| 盘中行情 | quote 字段可能更新时间不完全同步，需设置派生字段容差 | 待确认 |
| 复权日 K | 成交额/成交量通常保持未复权基础，不能与复权 OHLC 直接做均价量级比较 | 部分实现 |
| 北交所 | 代码格式、Provider 支持和单位可能与沪深不同 | 需按 Provider 能力策略区分 |

上述场景需要明确的交易日历、证券上市状态、停复牌或特殊交易事件上下文。缺少上下文时，不得猜测为正常交易，也不应把不确定情况直接判为硬错误。

## 8. 全仓调用链与 Adapter 解析边界（第一批盘点补充）

通过 PR #1 的全量 changed-file 清单和 patch 对照，已定位当前目标分支中显式调用点：

### 8.1 Quote 校验调用点

| 文件 | 调用位置 | 当前作用 |
|---|---|---|
| `internal/provider/netease.go` | Quote 适配器返回前 | 将解析后的 Quote 传给 `normalize.ValidateQuote` |
| `internal/provider/sina.go` | Quote 适配器返回前 | 同上 |
| `internal/provider/tencent.go` | Quote 适配器返回前 | 先验证源端 change/change_percent，随后重新计算规范涨跌字段 |

### 8.3 原始响应解析方式

| Provider | Quote 原始解析 | DailyBar 原始解析 | 字段问题丢失点 |
|---|---|---|---|
| NetEase | JSONP 解包后反序列化到结构体；数值字段使用 `json.RawMessage`，逐字段调用 `parseNeteaseNumber` | CSV/历史响应解析后构造 DailyBar，再进入公共 helper | 解析错误多被转换为通用文案；实际 RawMessage 未进入统一问题模型 |
| Sina | 文本 CSV/逗号分隔字段，按固定索引解析，必填解析器有字段名 | JSON 数值字段使用 `json.RawMessage`，逐行解析；解析失败只累计 rejectedRows | Quote 错误未保留实际值；DailyBar 只保留被拒数量 |
| Tencent | CSV 字段按索引读取，错误常只带字段索引 | JSON `[][]json.RawMessage`，前六列允许 string 或 number；对象等其他类型只增加 rejectedRows | 不支持的类型未保留字段索引、原始类型和行号 |
| Yahoo | JSON 反序列化到静态结构体；部分必填价格为非指针 float64 | OHLCV 数组使用指针，NULL 可识别；非预期 JSON 类型通常导致整体 Decode 失败 | Quote 非指针数值的缺失/null 可能表现为零值；整体 Decode 错误未转成字段级问题 |

`decodeSingleJSON` 使用 `UseNumber` 并拒绝尾随 JSON 内容，这是有价值的通用边界，但它本身不会自动生成字段路径级问题。

### 8.4 对新架构的直接影响

1. 字段问题必须在 Adapter 原始解析阶段和公共 Validator 阶段分别捕获；前者负责类型/解析错误，后者负责标准化模型的字段契约和业务关系。
2. DailyBar 的结构化问题必须在记录被过滤之前生成，否则 Probe 无法找回无效行。
3. 不能只在 Probe 再跑一次 Validator。Probe 应消费 Provider 采集过程中产生的校验报告；兼容期对尚未提供报告的旧 Provider 才使用受控 fallback。
4. 建议使用请求级、上下文隔离的 Validation Reporter 传递本次 Provider 调用的结果，避免全局状态和跨 Provider 串扰。Reporter 不持久化、不发网络请求；Probe 负责汇总。
5. `normalizeProviderDailyBars` 需要接收 context 或显式 report sink，并把每条记录的 row_index、symbol、trade_date 和问题保留下来；公共接口不应继续只返回字符串 warning。
6. Quote Adapter 的兼容期旧校验入口应包装新 Validator，但不应让 Probe 和 Adapter 各自维护规则副本。
