## 1. 产品目标与边界

WebUI 是个人 A 股研究工作台，核心闭环为：市场观察 → 研究对象 → 研究任务 → Run/Stage/Attempt → 证据与量化结果 → 研究结论 → 跟踪与通知。

Web 负责交互、请求编排、状态展示和有限的浏览器本地工作区。业务事实由 Server 暴露的真实 API 提供。Web 不访问模块 Repository/数据库/Provider，不复制数据质量、研究推理、量化策略、告警评估或任务状态机，不提供券商交易和自动下单。

技术栈保持原生 HTML、CSS、JavaScript ES Modules；不引入 React。优先复用现有文件和组件，不为匹配领域名机械拆分。

## 4. 当前页面与数据边界

- 市场总览、市场活动、个股行情、自选、选股、分析任务/Run Flow、本地研究笔记/报告、数据中心、告警草稿、通知偏好和设置中心已有页面。
- 当前选股仅针对已加载分页做浏览器本地筛选，不是全市场策略扫描。
- 本地研究笔记、报告归档、告警草稿和通知偏好必须标明本地范围，不伪装成服务端持久化。
- Run/Stage/Attempt 状态以 Researchflow 为权威；Web 不推断终态。
- Quant RiskDecision=block 是硬门禁；LLM、评分和用户偏好不能覆盖。
- Evidence 必须保留来源、授权、时间、定位和原始记录身份；无权内容不得展示。
- unknown 不等于 0；缺失、跳过、未配置、不支持、降级和失败分别表达。
- Owner Token、服务端密钥和第三方 Provider Key 不得暴露到浏览器。

## 5. 跨模块依赖

| 模块 | Web 消费原则 | 当前限制 |
|---|---|---|
| Server | 唯一业务 API 入口 | 以路由注册、认证和部署证据为准 |
| Platform | Session/CSRF/Fault/Request ID 等公共原语 | 原语存在不等于登录闭环已部署 |
| Data | 真实行情 API 与质量/时间字段 | 不在前端补算服务端数据质量 |
| News | 公开查询契约 | 不读内部 Repository，不把搜索候选当证据 |
| Research | Context/Evidence/Event/Claim 等公开 DTO | 结构化研究服务待接入 |
| Quant | 公开计算结果与 RiskDecision | 不以本地计算代替服务端算法 |
| Researchflow | Run/Stage/Attempt/Template | Web 不建第二套状态机 |
| LLM | 经 Server/Researchflow 受控调用 | 不把流结束等同 Run 成功 |
| Notification | 服务端订阅、投递状态 | 本地偏好不等于服务端订阅 |

## 6. 验收门禁

1. 浏览器只访问真实注册的 Server 路由，不自行拼造 API。
2. 本地状态与服务端持久化状态明确区分。
3. Session Cookie 使用 HttpOnly；CSRF Token 只存运行时内存；不在浏览器持有 Bearer/API Key。
4. Run/Stage/Attempt、PIT、质量、风险和授权状态按服务端 DTO 原样表达。
5. 320/375/600/768/900/1280/1600px 响应式回归。
6. WebUI Checks、Chromium Browser Smoke、真实 API 联调分别记录，不相互替代。
7. 无真实 API/权限/契约时，保持页面能力为待接入，不用 Mock 声称完成。
