## 1. 产品目标与边界

WebUI 是个人 A 股研究工作台，闭环为市场观察 → 研究对象 → 研究任务 → Run/Stage/Attempt → 证据与量化结果 → 研究结论 → 跟踪与通知。Web 负责交互、请求编排、状态展示和有限浏览器本地工作区。业务事实来自 Root Server 真实 API。Web 不访问模块 Repository/数据库/Provider，不复制质量规则、研究推理、量化策略、告警评估或任务状态机，不提供券商交易和自动下单。

技术栈保持原生 HTML、CSS、JavaScript ES Modules，不引入 React；优先复用现有模块。

## 2. 目标信息架构

| 导航 | 核心内容 |
|---|---|
| 市场观察 | 指数、市场宽度、行业/概念、市场活动、新闻线索 |
| 研究中心 | 个股/行业/事件、Context、Evidence、Event、Claim、Hypothesis、Scenario |
| 量化研究 | 指标、因子、趋势、策略、回测、风险和评估 |
| 研究任务 | Template、Run、Stage、Attempt、执行过程、取消、历史和结果 |
| 跟踪中心 | 自选、研究对象跟踪、订阅、告警与通知 |
| 数据中心 | 各模块真实运行状态与诊断 |
| 系统设置 | Session、安全、连接、模型、通知、数据源和个人偏好 |

目标导航不代表所有页面/API 已可用。

## 4. 不可违反的产品与数据规则

- 本地笔记、报告归档、告警草稿、通知偏好必须标明本地范围。
- Run/Stage/Attempt 终态以 Researchflow 为准；Web 不推断。
- Quant RiskDecision=block 是硬门禁，LLM/评分/UI 不得覆盖。
- Evidence 保留来源、授权、时间、定位和原始记录身份。
- unknown 不等于 0；缺失、跳过、未配置、不支持、降级和失败分别表达。
- Owner Token、服务端密钥、Provider Key 不得暴露浏览器。
- 不为 WebUI 展示提前增加无真实数据支撑的 API。

## 5. 跨模块依赖

具体生产方交付条件见《依赖/跨模块依赖与交付门禁.md》。Server 是唯一业务 API 入口；Platform 公共原语应复用；Data 质量规则归 Data；News 来源授权归 News；Research/Quant/Researchflow/LLM/Notification 的领域事实归各自模块。契约状态以项目级契约登记簿为准。

## 6. 验收门禁

1. 浏览器只访问真实注册的 Root Server 路由。
2. 每个新增 API 有明确用户场景、调用时机、领域 Owner、字段来源/语义、权限和验收证据。
3. 每项诊断定义 pass/degraded/fail/not_comparable/skipped/not_configured/not_supported 判定。
4. WebUI Checks、Browser Smoke、真实 API 联调、真实数据和部署验收分别记录。
5. 没有真实数据证据不得标记真实数据验收通过。
6. 本地状态与服务端持久化状态明确区分。
