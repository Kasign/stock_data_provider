## 维护规则
1. 总规划是模块任务状态唯一权威来源；当前任务文档只保留一个当前任务。
2. 任务完成后按唯一编号归档，记录范围、分支、SHA、测试/CI、真实数据和部署证据。
3. 架构文档描述代码职责与状态所有权，不维护任务排期。
4. 说明文档只维护功能事实、接口边界和诊断规则，不另立任务路线。
5. 依赖文档记录生产方交付门禁，不擅自修改其他模块状态。
6. 历史 SHA、分支和 CI 只对记录时点及对应对象有效；Mock、CI、真实 API 联调和部署验收不得互相替代。
7. 删除或移动文档前检查反向引用；无独立价值的重复副本才删除，审计证据应保留。
