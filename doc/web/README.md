## 维护规则
1. 任务状态只在总规划维护；当前执行细节只在当前任务文档维护。
2. 每个任务使用唯一编号；完成后在任务历史新增记录，保留提交、测试、真实数据和部署证据。
3. 历史 SHA/分支按记录时点理解，不作为当前状态。
4. API/DTO/认证以正式契约及 Root Server 实际注册为准。
5. 删除或移动文档时同步修复引用；不得删除仍有审计价值的历史证据。
6. Mock、CI、真实 API 联调和部署验收不得互相替代。
