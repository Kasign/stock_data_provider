## 文档维护规则
1. 产品路线、优先级、依赖和进度只写入《WebUI 整体规划》。
2. 功能说明只记录当前页面事实和明确标记的目标能力，不重复维护排期。
3. API 文档区分前端已封装、Handler 已注册、Root Server 已挂载、部署可达、真实数据验收通过。
4. 公共契约以 doc/ 公共文档和模块代码为准，Web 文档只记录消费边界。
5. 已完成专项保留为历史证据；过期下一步安排删除或回链总体规划。
6. 不因路线图增加而自动新增页面、API、状态机或前端物理模块。
