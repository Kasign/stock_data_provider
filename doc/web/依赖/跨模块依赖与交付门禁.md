# Web 跨模块依赖与交付门禁

更新时间：2026-11-18  
维护分支：feat/web

> 本文记录 Web 消费其他模块的前置条件，不修改生产模块任务状态，也不代替项目级契约登记簿。契约冻结、代码实现、Server 注册、部署可达和真实数据验收是不同状态。

| 编号 | 生产方 | Web 消费场景 | 必须交付 | 接入门禁 | 当前边界 |
|---|---|---|---|---|---|
| WEB-DEP-01 | Platform + Server | Owner Session、Fault、Request ID | Session HTTP 契约、Cookie/CSRF/Origin、Root Server 注册 | 自动化验收通过且 SRV-CTR-002 正式冻结；目标部署入口浏览器验收归 W5-E | W2-A 自动化实现验收已通过；SRV-CTR-002 为 freeze-ready、待项目负责人确认冻结；真实部署入口验收待 W5-E |
| WEB-DEP-02 | Data + Server | 市场、个股、行情和诊断 | 已注册路由、DTO、来源/质量/Freshness/覆盖率/时间语义 | 真实 Root Server 请求；Provider 证据按 Data 验收 | 复用现有 API，不重建质量规则 |
| WEB-DEP-03 | News + Server | 新闻线索和来源证据 | 公开查询用例/DTO、来源授权、版本和引用定位 | 授权检查与真实响应 | 不读内部 Repository，不把候选当证据 |
| WEB-DEP-04 | Research + News + Server | Context/Evidence/Event/Claim/Hypothesis/Scenario | Research DTO、News Evidence 引用、资源授权、PIT/时间语义和路由 | 真实对象/证据响应及越权拒绝 | 本地笔记不是 Evidence |
| WEB-DEP-05 | Quant + Data + Server | 因子、趋势、策略、回测、风险 | 版本化 DTO、单位/时间/PIT/质量/RiskDecision 和路由 | 真实计算结果；block 为硬门禁 | 本地 MA/RSI/MACD 不是 Quant API |
| WEB-DEP-06 | Researchflow + Server | Template、Run、Stage、Attempt、取消、历史 | Template ref/version、参数 Schema、Run DTO、幂等/错误/授权和路由 | SRV-CTR-001 解除 deferred 并冻结，真实生命周期验收 | 内部 Worker 不等于浏览器 HTTP API |
| WEB-DEP-07 | LLM + Server/Researchflow | 受控问答、结构化解释 | 服务端 Gateway、输出 Schema、权限、超时/取消/审计 | 浏览器不得持有模型密钥 | 无正式契约不新增 API |
| WEB-DEP-08 | Notification + Server | 收件箱、订阅、投递状态 | Recipient/Subscription/Channel/Delivery DTO、权限和真实投递记录 | 真实投递验收 | 本地偏好不等于服务端订阅 |
| WEB-DEP-09 | 领域归属决策 + 对应生产方 | 自选同步、告警、报告/组合 | Portfolio/Watchlist/Alert/Report Owner、持久化和 API 契约 | 领域决策及真实 API 完成 | 暂保留本地能力并标明范围 |

## 公共接入门禁

新增 API/字段前必须明确用户场景、调用时机、领域与路由 Owner、契约编号/版本、字段来源/单位/时间/空值语义、认证与资源授权、分页/超时/取消/幂等/错误语义，以及自动化和真实环境验收证据。每项诊断定义 pass、degraded、fail、not_comparable、skipped、not_configured、not_supported 判定。

缺少前置条件时只记录依赖，不猜接口，不用 Mock 填充真实业务页面。生产模块状态以各模块总规划为准，契约状态以项目级登记簿为准。
