# WebUI 整体规划

更新时间：2026-11-04（P0-B3 最终验收代码：f86170981421ad1408d80c666f06c428ad8f7421）
目标分支：`feat/webui-market-data-console`
适用范围：仅规划和管理 WebUI（`web/**`）及其专属文档（`doc/web/**`）。除明确获批的文档路径修正外，不修改 Go、Provider、数据库、服务端 API、OpenAPI 实现和部署配置。

> 本文是 WebUI 后续开发的唯一总体规划与进度入口。新任务、优先级、执行状态、验收结果和下一步安排统一更新在本文。其他专项文档只保留功能契约、技术细节和验收标准，不再另行维护总体任务顺序。

## 1. 产品目标与边界

围绕国内 A 股市场观察、股票发现、个股研究、分析任务和持续跟踪，形成可持续使用的研究工作台。

- WebUI 负责页面交互、请求编排、状态展示和浏览器本地工作区。
- 行情事实、数据来源、质量状态、Provider 能力和分析结果以服务端真实响应为准；前端不补造数据、不将缺失值补零。
- 浏览器本地数据（自选股、筛选方案、研究笔记、报告归档、偏好等）必须明确标注本地范围，不伪装为服务端持久化或跨设备同步。
- 不提供券商交易下单能力。
- 使用原生 HTML、CSS、JavaScript ES Modules，不引入 React。
- 只修改当前 WebUI 分支；不创建新分支。代码按功能批次修改和提交，使用中文提交说明。
- 数据侧能力未完成真实验证时，WebUI 只记录依赖和缺口，不复制数据质量规则，不通过模拟响应宣称真实联调完成。

## 3. 当前基线

### 3.1 已具备的页面与能力

- 市场总览：指数、市场宽度、板块排行、涨跌停池、人气榜、龙虎榜及市场级资金流历史入口。
- 个股行情：证券搜索、实时行情、全市场分页、日 K 与前端技术指标。
- 自选股：本地分组、批量操作、字段显示/排序、批量行情和研究入口。
- 个股研究：行情、日 K、估值、财务、资金流、筹码、公告等按需读取；市场榜单/全市场/自选股可直达研究。
- 分析任务：创建任务、阶段事件、Run 结果、错误状态、最近任务本地引用及报告归档。
- 选股：当前已加载分页上的本地条件筛选、方案管理、结果视图、批量加入自选和 CSV 导出；不是服务端全市场策略扫描。
- 数据中心：服务健康、Provider 静态能力、被动诊断、主动探测和探测历史展示；真实部署能力仍需数据侧样例及环境验证。
- 设置中心：10 个设置分组已建立，部分为浏览器本地偏好，部分服务端能力仍待数据 API。

以上是功能基线，不代表所有数据源、Provider 和生产环境均已验收。

### P0-C：全市场、筛选与自选股请求生命周期统一审查

状态：**进行中（首批已完成代码修复，等待本轮 CI；继续覆盖剩余请求链路）**

首批审查与修复（代码基线：`cf6c0b6d0b9631456b32f4617da1a33e0c3879b5`）：
1. **全市场分页与本地筛选快照：** `getCurrentPageSnapshot()` 暴露加载状态和请求代际；筛选快照在分页刷新开始时立即失效，刷新期间禁止重新应用、导出和批量加入，刷新完成后必须基于新快照重新应用。
2. **筛选导出状态：** 结果失效或当前过滤结果为空时禁用导出按钮，避免空操作按钮仍可点击。
3. **自选股批量行情成员一致性：** 成功快照记录请求时的证券成员集合；自选股增删导致成员集合变化时，立即清除旧批量快照；请求返回前再次核对成员集合，丢弃请求期间成员已变化的响应。仅调整分组或显示顺序不改变行情请求范围。
4. **失败快照标识：** 请求失败保留上次成功行情时，列表行明确显示“上次成功快照”及采集时间。
5. **超时与取消：** 全市场分页和自选股批量行情请求设置 30 秒超时，超时会终止底层 fetch；连接配置变化仍通过 AbortController 取消并由请求代际隔离晚到响应。
6. **自动化证据：** 新增筛选刷新竞态浏览器用例、自选股行情成员变化浏览器用例和市场接口超时单测；当前等待代码提交对应 CI 结果。

剩余检查范围：
- 全市场连续刷新、分页/页大小/复权变化及页面离开/返回时的请求代际和 UI 状态。
- 自选股请求失败后旧快照、部分成功、无返回项、列表增删和分组变更边界。
- 个股研究页复用行情缓存时的标的身份、请求取消和快照边界。
- 股票搜索、单股行情查询与 API 地址切换时的取消、代际、错误恢复。
- 不重复请求、不将旧结果伪装为新结果；失败后保留旧数据必须明确标记来源和时间。

实施边界：仅 WebUI 请求编排与状态管理；如发现服务端契约问题，记录到公共契约缺口文档，不擅自修改数据侧代码。
