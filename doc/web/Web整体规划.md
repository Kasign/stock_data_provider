目标分支：`feat/webui-market-data-console`

> 本文是 WebUI 后续开发的唯一总体规划与进度入口。新任务、优先级、执行状态、验收结果和下一步安排统一更新在本文。其他专项文档只保留功能契约、技术细节和验收标准，不再另行维护总体任务顺序。

## 1. 产品目标与边界

围绕国内 A 股市场观察、股票发现、个股研究、分析任务和持续跟踪，形成可持续使用的研究工作台。

- WebUI 负责页面交互、请求编排、状态展示和浏览器本地工作区。
- 行情事实、数据来源、质量状态、Provider 能力和分析结果以服务端真实响应为准；前端不补造数据、不将缺失值补零。
- 浏览器本地数据（自选股、筛选方案、研究笔记、报告归档、偏好等）必须明确标注本地范围，不伪装为服务端持久化或跨设备同步。
- 不提供券商交易下单能力。
- 使用原生 HTML、CSS、JavaScript ES Modules，不引入 React。
- 只修改当前 WebUI 分支；不创建新分支。代码按功能批次修改和提交，使用中文提交说明。
- 数据侧能力未完成真实验证时，WebUI 只记录依赖和缺口，不复制数据质量规则，不通过模拟响应宣称真实联调完成。

## 3. 当前基线

### 3.1 已具备的页面与能力

- 市场总览：指数、市场宽度、板块排行、涨跌停池、人气榜、龙虎榜及市场级资金流历史入口。
- 个股行情：证券搜索、实时行情、全市场分页、日 K 与前端技术指标。
- 自选股：本地分组、批量操作、字段显示/排序、批量行情和研究入口。
- 个股研究：行情、日 K、估值、财务、资金流、筹码、公告等按需读取；市场榜单/全市场/自选股可直达研究。
- 分析任务：创建任务、阶段事件、Run 结果、错误状态、最近任务本地引用及报告归档。
- 选股：当前已加载分页上的本地条件筛选、方案管理、结果视图、批量加入自选和 CSV 导出；不是服务端全市场策略扫描。
- 数据中心：服务健康、Provider 静态能力、被动诊断、主动探测和探测历史展示；真实部署能力仍需数据侧样例及环境验证。
- 设置中心：10 个设置分组已建立，部分为浏览器本地偏好，部分服务端能力仍待数据 API。

以上是功能基线，不代表所有数据源、Provider 和生产环境均已验收。

## 6. 执行与验收流程

每批任务按以下顺序执行：
1. 核对目标分支最新 HEAD、工作区/提交状态和相关文档。
2. 明确本批范围、禁止触碰目录、依赖和验收标准。
3. 审查现有实现，先列问题与风险；复杂重构先给方案确认。
4. 按功能完成实现与测试，不拆成大量零碎提交。
5. 进行代码审查、静态检查、单元测试和必要的浏览器测试。
6. 更新本文状态、专项验收记录和必要的功能/API 文档。
7. 中文提交，记录提交 SHA、测试命令、CI 链接、未完成项和原因。
8. 报告当前阶段、已完成事项、阻塞项和下一任务。
