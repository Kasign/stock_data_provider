技术栈：原生 HTML、CSS、JavaScript ES Modules；不使用 React。

> 本文记录页面功能事实和目标信息架构。总体路线、优先级和进度只维护在《WebUI 整体规划》。

## 1. 产品目标

WebUI 目标是形成以研究任务为中心的个人 A 股研究工作台。前端负责交互、请求编排、状态展示和浏览器本地工作区；行情、新闻、研究证据、量化结果、任务状态、风险门禁和通知投递以服务端真实响应为准。不提供券商交易下单。

## 3. 当前页面能力事实

### 3.1 市场观察
- 指数行情、市场宽度、行业/概念排行、涨跌停/炸板池、人气/飙升榜、龙虎榜、交易日历和市场时段信息。
- 市场级资金流历史依赖有权限的 Tushare moneyflow_mkt_dc；不得用个股资金流求和或涨跌分布推算。
- 历史情绪联动使用真实 trade_date；不代表不同 Provider 数据来自同一原子快照。
- 只在服务端返回合法证券代码时提供研究入口；不从展示名称反推代码。
- 缺失、质量降级、Provider 未配置和接口错误按真实响应展示，不补零。

### 3.2 个股行情
- 证券搜索、单股行情、日 K、前复权/后复权/不复权、全市场分页行情。
- MA/RSI/MACD 是基于已加载日 K 的前端派生指标，不是 Quant 服务端因子 API。
- 全市场分页由用户显式触发，只读取当前页；页内本地筛选不代表全市场筛选。
- 缺失值显示未知/未提供，不补 0；保留来源、时间和质量原因。

### 3.3 自选股与本地筛选
- 自选股是浏览器本地清单，支持分组、排序、字段显示、批量操作和研究入口；不跨设备同步，不等于 Portfolio。
- 本地筛选方案组合涨跌幅、换手率、成交额、MA5/MA20 条件，应用于最近一次成功加载的当前分页。
- 筛选结果区分命中、未命中、待判断；缺失字段按未知处理。
- 批量加入自选和 CSV 导出只作用于当前页通过快照校验的结果，不自动翻页、不执行服务端扫描。

### 3.4 个股研究与本地研究记录
- 个股研究按需读取行情、日 K、档案、板块、财务、估值、公告、个股资金流和筹码分布。
- 补充资料按模块主动加载；打开页面不自动请求所有数据。
- 研究笔记和 Run 报告归档保存在当前浏览器，支持搜索、编辑、详情、Markdown 下载及关联任务跳转。
- 本地笔记/报告不等于 Research 服务端 Evidence/Claim/Hypothesis，也不等于服务端 Report。
- 结构化研究接入后，区分原始证据、研究解释和模型生成内容，保留证据来源及授权边界。

### 3.5 分析任务与 Run Flow
- 当前页面可创建分析任务、查询任务状态和阶段事件、读取 Run 结果并展示执行过程。
- 最近任务只保存有限数量的浏览器引用，不是服务端完整历史列表。
- Run/Stage/Attempt 终态以 Researchflow 真实响应为准；前端不得通过 LLM 流式输出推断任务成功。
- 服务端历史分页、模板、取消和综合结果未取得真实路由/权限/部署验收前，不添加虚构请求。

### 3.6 数据中心与诊断
- 当前覆盖 Web 静态检查、行情/分析服务健康端点、Provider 能力清单、只读运行诊断、用户显式触发的主动探测及历史记录。
- Provider 注册/能力声明不等于健康；跳过/未配置/不支持不等于通过。
- 领域质量和业务规则由服务端模块判断；前端只校验响应结构并忠实展示。

### 3.7 告警、通知与设置
- 告警规则当前仅是本地草稿，不代表后台评估或触发。
- 通知偏好是本地设置，不代表服务端订阅、渠道或消息投递。
- 连接与个人偏好存在浏览器本地配置；Owner Token、服务端密钥和第三方 Provider Key 不得进入浏览器。
- Web Session/Cookie、CSRF、登录限流和资源授权以 Server/Platform 实际接入为准。

## 4. 页面状态规则

| 状态 | 页面表达 |
|---|---|
| loading | 请求执行中，防止重复提交 |
| success/data | 显示真实响应及来源/时间/质量 |
| empty | 请求成功但无可展示记录 |
| unknown/not_provided | 服务端未提供，不解释为 0 |
| skipped/not_configured/not_supported | 分别展示原因，不映射为成功 |
| degraded/stale | 质量与新鲜度独立表达 |
| failed | 展示可诊断错误，不用旧数据冒充当前结果 |
| not_integrated | 明确待接入，不渲染虚构业务数据 |

## 5. Web 不代替服务端完成的工作

Provider 探测和质量规则；Research Evidence 授权、事件归并、Claim/Hypothesis 生成；Quant 因子、策略、回测和风险决策；Researchflow 状态机、取消和历史；LLM 凭据管理与工具执行；Notification 订阅、告警评估、渠道发送和重试。Portfolio/Alert/Report 的领域对象与持久化等待领域归属正式确定。

## 6. 本地数据范围

浏览器本地数据包括主题/偏好、自选股及分组、最近任务引用、研究笔记、Run 报告归档、选股方案、告警草稿和通知偏好。具体存储键、Schema、导入/导出范围以当前代码和专项测试为准。

本地存储不能表述为服务端持久化、跨设备同步或正式投资组合。工作区备份不包含服务器环境变量、数据库内容和服务端凭据。
