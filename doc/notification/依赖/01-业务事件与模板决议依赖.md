# 依赖 01：业务事件与模板决议

状态：BLOCKED（等待业务 Owner）

## 需要的输入

1. 每个事件的 event_type、schema_version、Payload Schema、触发时点、subject_ref、幂等键由生产方 Owner 冻结。
2. 非空 Subscription Filter 的字段语义、Schema 版本和匹配规则由对应事件 Owner 冻结；Notification 不自创 DSL。
3. 首批事件的真实模板文案、变量绑定、空值语义和渠道专属格式由业务 Owner 提供。
4. 每个模板变量必须关联 Payload 字段，注明来源、类型和展示语义。

## Notification 责任

校验并注册已冻结 Schema/Golden；按固定模板版本渲染；未知字段、未声明变量、非标量变量和不支持 Filter fail closed。不生成业务事实、模板内容或订阅规则。

## 验收证据

业务 Owner 决议、Schema/Golden、生产方 Contract Test 和模板渲染测试。缺少输入时标记 not_comparable，不以合成 Fixture 代替真实业务验收。
