## 凭据安全

- 群机器人 Webhook URL 如果包含 key，整个 URL 都是敏感凭据，不应提交到仓库、写入文档或放入普通聊天记录。
- 建议将 Secret 放入部署环境的受控配置/密钥注入通道；Server 通过 Platform `config.Secret` 将值注入具体 Adapter。
- 具体 Adapter 使用 Platform `httpclient.Client.Bind`，按企业微信官方主机名和必要端口创建固定目的地址策略；不允许任意 URL 由业务数据控制。
- ChannelConfig Repository 只保存 SecretRef，不保存 Secret 明文。

## 验收门禁

- 无真实凭据和受控测试目标：NOT_COMPARABLE。
- 明确拒绝且 Provider 证明未接受：按白名单和 RetryPolicy 决定是否重试。
- 请求可能到达 Provider 但缺少可靠结果：unknown，禁止盲目重发。
- 本次验收只证明 Webhook 请求成功且用户确认目标群收到消息；不据此宣称 Provider 具备幂等、Lookup、Retry-After 或可靠回执，也不代表生产投递生命周期 L3 全面通过。

## 公共能力复用

使用 Platform Secret 与受控 HTTP Client；不得在 Notification 重建 Secret Store、通用 HTTP Client 或凭据管理。
