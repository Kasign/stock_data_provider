# Notification 任务拆分与验收

|---|---|---|---|---|
| NTF-001 | P0 | Event/Subscription/Delivery 契约 | GOV-004、Platform | 事件版本、订阅范围、幂等键和状态定义 |

| NTF-007 | P2 | Diagnostics/API | NTF-001~006 | 发送测试、状态查询、失败原因和诊断接入 |

## 验收门禁
- 真实渠道受控测试发送；无凭据标记 skipped/blocked，不标记通过。
- 幂等和重试测试证明不会重复发送。
- 发送失败不影响上游业务事务。
- Secret/目标/通知内容按安全策略脱敏。
- 测试发送不得触达未明确指定的真实订阅者。
