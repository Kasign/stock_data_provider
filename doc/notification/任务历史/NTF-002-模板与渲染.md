## 本轮 Review 结论

- Registry 按模板 ID 和版本精确解析，不回退 latest；同一版本不同定义拒绝覆盖。
- 模板变量必须声明绑定，绑定路径按 JSON Pointer 解析且最终值必须是标量；模板语法限制为静态文本和 allowlist 字段引用。
- HTML Body 使用标准库 `html/template`；Subject 拒绝 Unicode 控制字符；Subject 与 Body 共享输出上限。
- Repository 创建时校验定义并计算 JCS Digest；重复键时读取并比较完整定义；读取时重新验证定义和 Digest。
- 批量装载在所有版本校验和编译成功后统一写入 Registry，避免部分装载。
- 未发现需要立即修复的确定性代码缺陷。源码 Review 未执行本地测试；当前 SHA 的 Notification MariaDB lifecycle integration Job 已由 GitHub Actions 验证成功，完整 workflow 尚未结束。
