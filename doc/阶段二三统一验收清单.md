### 2. 固定样本与质量对账

- [ ] 覆盖沪市主板、深市主板、创业板、科创板、北交所。
- [ ] 覆盖正常交易日、停牌日、非交易日、新股、ST/风险警示及退市样本。
- [ ] 对比同一证券、同一交易日、同一复权基准的 OHLC、涨跌幅、成交量和成交额。
- [ ] 核实成交量单位（股/手）、成交额单位（元/万元/亿元）及百分比单位（百分点/比例）。
- [ ] 核实前复权/后复权的参考日期、复权因子来源和计算结果。
- [ ] 核实报告期、源端发布时间、服务采集时间和系统观察时间，不将报告期末当作公告日。
- [ ] 验证 null、真实零值、空列表、字段缺失、接口无权限和非交易日的区分。
- [ ] 验证分页终止、源端总数、去重、排除记录和覆盖率。
- [ ] 验证 Provider 失败切换、部分字段降级和低质量数据不覆盖高质量缓存。
- [ ] 验收证据记录代码 SHA、脱敏样本、响应行数、字段对账结果、质量状态和错误分类。

## 三、统一验收记录模板

每次验收追加一条记录，至少包含：

| 字段 | 内容 |
|---|---|
| 日期/环境 | 实际执行时间及环境 |
| 代码基线 | 完整 Git commit SHA |
| Provider/API | Provider 名称、能力或 API 路径 |
| 样本范围 | 脱敏代码、交易日、报告期或查询区间 |
| 请求结果 | HTTP/业务状态、耗时、重试、错误分类 |
| 覆盖证据 | 源端总数、返回数、分页终止、重复/排除数 |
| 字段对账 | 字段存在率、单位、精度、来源和时间语义 |
| 质量结论 | valid/degraded/stale/invalid/unknown |
| 最终判定 | 通过、降级可接受、不通过、权限阻塞、限流阻塞 |
| 后续动作 | 修复项、责任能力及复验条件 |

真实凭据、Cookie、完整请求 URL 和个人敏感数据不得写入本文档。
