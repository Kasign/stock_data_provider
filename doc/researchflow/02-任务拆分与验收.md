## 验收门禁
- DAG 无环；必需/可选阶段和 skipped 语义明确。
- 状态迁移、超时、取消、重试、并发和恢复有测试。
- 失败 Attempt 不覆盖历史；幂等键不产生重复副作用。
- 部分结果标记 incomplete/degraded。
- API/DI/Worker/根 Migration 注册不在模块分支提前修改。

### 状态机验收补充

- Stage 的 blocked 是调度前置条件未满足，不等于一次执行失败；必须记录阻断依赖和 reason_code。
- Stage 重试时 Stage 状态由 Application 按策略重新进入 ready，历史 Attempt 保留；不得把终态 Attempt 改回 running。
- RetryStage 必须校验 Run 未取消、deadline 尚有效、重试预算未耗尽、依赖输出仍有效。
- Run 取消后不得再启动新 Stage/Attempt；已在运行的 Attempt 必须收到取消信号并最终记录 cancelled 或其真实完成结果。
- partial 必须附带缺失 Stage、降级原因和结果覆盖范围；不得仅凭一个 Stage degraded 自动推断 Run partial。
- FLOW-004 自有 Executor 的并发上限、队列容量、租约/超时、进程重启恢复策略必须明确；不把 Platform Task Queue 当作无条件可用依赖。

### 本模块可独立开工边界

FLOW-001~003 可先独立完成；FLOW-004 在 Executor Port 和资源预算契约明确后可开发自有实现，不等待 Quant/Research/LLM/Notification 的生产 Facade。
