### 初步缺口（待逐项对照冻结契约）

1. DTO/Schema/Golden 的现有测试已覆盖多个结构边界，但尚未形成“冻结契约条目 → DTO 字段 → Schema 约束 → Golden → 测试用例”的完整矩阵。
2. 跨模块 Fault/HTTP 错误投影应复用 Platform 公共契约，需确认 Researchflow Application 错误是否逐项映射且不重复定义公共 Fault。
3. HardRiskGateRegistry 和 Stage Output Registry 的通用机制存在；需要检查实际生产模板注册是否仅包含有真实 Provider、Schema、消费者的条目。
4. 不把当前测试替身、单元测试或旧 SHA CI 结果标记为真实生产验收。
