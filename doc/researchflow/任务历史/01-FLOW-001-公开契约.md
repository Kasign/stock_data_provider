- 机器契约：`doc/researchflow/schema/`、`doc/researchflow/golden/`
- 主要测试：`publicdto/dto_test.go`
- 代码验收 SHA：`2df5ee14b5c39613a10f124da463ae3f939e13b3`；Actions Run 44293452576 中 Researchflow module gofmt/tests/race/vet Job success。

## 已确认的剩余缺口

1. FLOW-CTR-001/002 对 CreateRun/CancelRun/RetryStage 命令字段有明确决议，但独立 Schema/Golden/消费者测试映射尚未完整。
2. FLOW-CTR-003 执行上下文/ResearchContext 字段映射尚未形成统一机器契约。
3. ResultSummary 的生产语义已明确：quality_status 当前只输出 valid/degraded，独立于 Run.status；coverage 分母为实际创建的适用 Stage，分子按 Stage 成功/降级/可选 no_impact skip 计算，ExcludedStages 不计入分母；actionability_status 独立表达 HardRiskGate。Summary 资源版本绑定继续按 schema_version/ref 契约验收。
4. Researchflow 错误应投影到 Platform Fault；不复制公共 Fault 或 HTTP ErrorEnvelope。
5. FLOW-CTR-004 Stage Provider Envelope 的项目登记簿状态与模块 Schema/Golden/Registry 资产仍需项目契约 Owner/Integration 核对。

- 通过：生产 DTO 绝对时间以 UTC Z 输出；Run 终态/非终态 Summary 引用由运行时校验保证；冻结字段映射和测试满足。
- 降级：无；契约结构校验不应静默放宽。
