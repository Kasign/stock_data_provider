## 已确认的剩余缺口

1. GOV-CTR-002 要求 RFC3339Nano UTC 且以 Z 结尾；Run/Stage/Attempt 时间字段目前只使用 date-time format，Schema 未强制 Z。
2. Run Schema 只要求终态 result_summary_ref 非空，没有同时禁止非终态携带非空 ResultSummary 引用。
3. FLOW-CTR-001/002 对 CreateRun/CancelRun/RetryStage 命令字段有明确决议，但独立 Schema/Golden/消费者测试映射尚未完整。
4. FLOW-CTR-003 执行上下文/ResearchContext 字段映射尚未形成统一机器契约。
5. FLOW-CTR-004 ResultSummary 的 quality_status 枚举、coverage 分母和 Summary 资源版本绑定仍缺完整权威口径，禁止本模块猜测。
6. Researchflow 错误应投影到 Platform Fault；不复制公共 Fault 或 HTTP ErrorEnvelope。

## 验收口径

- 通过：UTC Z、终态/非终态引用约束、冻结字段映射和测试全部满足。
- 降级：无；契约结构校验不应静默放宽。
- 失败：偏移时区、缺失必需字段、终态缺 Summary、非终态携带终态 Summary 引用、未知字段或不支持版本。
