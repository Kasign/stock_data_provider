# 开发、部署与本地运行说明

更新日期：2026-10-30

## 1. 仓库模块

- web/：原生 HTML/CSS/JavaScript ES Modules WebUI。
- services/market-data/：Go 行情数据服务，提供 A 股行情、证券、市场和 Provider API。
- 分析服务：提供异步分析任务、阶段事件和运行结果。
- go-core/、python_bridge/：数据计算/Provider 兼容模块，具体启用范围以当前 Compose 与服务配置为准。

## 2. WebUI 本地开发

进入 web/ 后查看 package.json 的 scripts。页面通过同源代理访问：
- 行情服务：默认 /market-api。
- 分析服务：默认 /analysis-api。

不要在浏览器端填写 Docker 服务名、容器端口或外部 Provider 密钥。API Key 只通过请求头 X-API-Key 发送给行情服务。

## 3. 服务端部署

以仓库根目录 docker-compose.yml、根目录 .env.example 和服务目录配置为准。部署时需要确保 WebUI Nginx 上游名称与 Compose 服务名一致，健康检查与浏览器代理路径一致。

## 4. 配置安全

- web/ 中的连接设置只保存当前浏览器的代理路径和行情 API Key。
- 不通过浏览器修改服务端 .env、Provider 凭据、MariaDB/Redis 或 Docker 配置。
- Provider 密钥应通过服务端环境变量/受控部署配置管理。
- 工作区备份不包含 API Key、行情缓存、完整分析报告、服务端配置和数据库内容。

## 5. 运行与验收

完整浏览器验收以 doc/WebUI提测验收清单.md 为准。不要把静态检查、HTTP 健康检查或 Provider 能力声明当作真实业务数据验收。
