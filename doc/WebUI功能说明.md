# WebUI 功能与页面说明

更新日期：2026-11-03
开发分支：feat/webui-market-data-console
技术栈：原生 HTML、CSS、JavaScript ES Modules；不使用 React。页面不伪造行情或服务端配置。

## 1. 产品目标

围绕国内 A 股市场观察、热点发现、个股研究、任务分析和持续跟踪形成工作台。WebUI 负责交互和展示；行情事实、数据来源、质量状态及分析任务结果以服务端真实响应为准。当前不提供券商交易下单能力。

## 3. 页面模块

### 3.1 市场总览
- 核心指数行情。
- 市场涨跌分布/宽度。
- 行业与概念排行。
- 涨停、跌停、炸板池。
- 个股人气/飙升榜。
- 市场时段状态、数据来源与质量提示。
- 市场级每日资金流历史：按日期范围读取 Tushare `moneyflow_mkt_dc`，展示指数、主力净流入及比例、来源、采集时间和质量原因；Provider 未启用/无权限时显示真实错误。
- 成交额与资金净流入分别展示；市场级资金流不是个股资金流求和。
- 不以涨跌分布推算资金流，不以单日快照伪造历史情绪曲线。

### 3.2 个股行情与研究
- 按中文名称、六位代码或标准代码搜索证券。
- 实时行情与日 K；支持前复权、后复权、不复权。
- 前端计算 MA、RSI、MACD 等技术指标；计算结果需基于有效日 K 数据。
- 个股档案、估值、财务、所属板块、公告、资金流和筹码分布按需加载。
- 保留源端时间、采集时间、来源、质量状态和降级原因。

### 3.3 自选股
- 最多 50 条本地自选股，支持搜索、别名、单只/批量移除、批量调整分组、快捷查询和分析。
- 批量操作只作用于当前筛选结果中显式勾选的股票；全选仅选择当前可见筛选结果。
- 支持按最近更新、代码、名称、最新价、涨跌幅、成交额、换手率排序及升/降序；行情排序只使用已加载的真实行情，缺失项始终排在末尾。
- 辅助字段支持勾选显示和上移/下移排序：添加/更新时间、行情快照、今日分析、任务状态、分析结果。
- 排序、显示字段与字段顺序保存在当前浏览器；工作区 JSON 支持备份/迁移。
- 研究列表不自动批量请求所有自选股；当前没有服务端自选股跨设备同步。

### 3.3.1 选股与筛选
- 本地条件支持涨跌幅、换手率、成交额、MA5、MA20，支持 AND/OR 组合；字段范围统一校验，方案支持新建、更新、另存为、载入和删除，并限制最多 30 个；仅保存当前浏览器本地。
- 可将条件应用于“个股行情”最近一次成功加载的当前分页；结果明确标注页码、每页数量和复权口径，不自动翻页、不代表全市场扫描。
- 缺失字段按未知处理，不补零；AND/OR 使用三态判断，分别统计命中、未命中和无法判断数量。
- 支持保存、更新、另存为、载入和删除本地筛选方案；最多 30 个，仅保存在当前浏览器。
- 当前仍无服务端筛选表达式、行业/概念筛选、扫描任务、候选理由或选股历史 API。

### 3.4 分析任务
- 创建分析任务并跟踪 queued/running/partial/succeeded/failed 等状态。
- 按事件序号续读阶段事件，避免旧请求覆盖当前任务；任务状态/事件请求默认 15 秒超时，Run 结果请求默认 20 秒超时。
- 切换任务、切换分析 API 地址或重新读取 Run 结果时取消旧请求；超时错误按可重试网络错误处理，旧请求代际校验继续作为第二道隔离。
- 创建任务请求设置 30 秒等待上限；超时明确标记为“创建结果未知”，提示先核实服务端，不自动重复提交。
- 查询运行结果并生成本地 Markdown 报告。
- 最近任务最多保存 10 条浏览器引用，支持股票/任务 ID/状态/错误原因搜索、状态/类型和创建日期筛选；本地记录保留失败代码与限长错误摘要。任务本体由分析服务持久化，Run 报告可下载或另行归档到当前浏览器。 列表展示任务类型；历史持仓复核可筛选，未知类型按原始值显示。 读取时严格校验标的列表格式（最多 100 只），并拒绝不存在的日历日期筛选；异常记录不会被静默修剪后覆盖。
- 当前没有服务端任务列表分页 API；本区不是服务端完整历史，超过本地最近 10 条或更换浏览器后无法从此处检索。

### 3.4.2 服务端任务历史 API 缺口（待数据层实现）

当前 OpenAPI 仅定义 `POST /api/v1/analysis/tasks` 创建任务，以及按 Task ID 查询状态和阶段事件；集合路径尚无 `GET`，因此 WebUI 无法恢复完整历史。以下是供数据层评估的接口建议，不代表当前服务端已实现：

- 建议新增 `GET /api/v1/analysis/tasks`，与创建任务共用集合路径；仅查询当前分析服务自身持久化的任务。
- 建议筛选参数：`status`、`task_type`、`symbol`、`created_from`、`created_to`；日期时间使用带时区的 RFC 3339，边界按任务 `created_at` 判断。
- 建议分页参数：`limit`（默认 20，范围 1–100）和不透明 `cursor`；使用 `created_at DESC, task_id DESC` 稳定游标分页，游标需绑定筛选条件，避免翻页时混入不同查询。
- 建议响应：`items`、`next_cursor`、`has_more`；不强制返回昂贵的全量 `total`。每条任务需提供现有 Task 字段，并包含可筛选/展示的 `symbols`。
- 失败记录保留服务端 `failure_code` 和限长 `error_message`；任务列表不应内嵌完整 Run 结果，详情仍按 Run ID 单独读取。
- 接口使用分析服务自身的认证和 API 路径，不附加行情服务 `X-API-Key`。不得将浏览器最近 10 条引用与服务端分页结果混合后伪装为同一数据源。

验收要求：首屏/翻页/筛选/清空筛选、游标失效、非法日期范围、服务端错误、任务状态更新和跨页去重均有测试；切换分析 API 地址时不得读取另一服务的游标或任务。

### 3.4.1 研究记录与报告归档
- 研究笔记保存在当前浏览器，可关联股票代码、Task ID、Run ID，并支持关键词检索、编辑和删除。笔记和报告归档均校验唯一 ID，并在写入后逐项回读比对；损坏或重复记录不会覆盖旧数据。标的代码、任务/运行 ID、标签数量和长度均严格校验；超限或格式异常时拒绝静默截断，避免归档内容与用户输入不一致。
- 研究报告卡片支持“基于报告写笔记”，自动带入报告的首个标的、Task ID、Run ID；用户补充研究内容后再保存，不自动生成研究结论。
- 对已从分析服务读取并校验身份的 Run 结果，可归档完整结果 JSON，最多保存 30 份。
- 报告按股票、Task ID、Run ID、状态和归档日期检索；支持详情查看、Markdown 下载、删除和关联任务跳转。
- 归档保留分析 API 地址以区分不同服务端的 Run ID；同一地址下同一 Run 重复归档幂等。
- 报告与笔记均为浏览器本地数据，不等于服务端报告历史；清理浏览器数据或更换设备不会自动同步。

### 3.6 告警与通知
- 告警规则当前仅支持浏览器本地草稿，包含单只股票/当前自选股范围、价格/涨跌幅/换手率阈值、严重级别和草稿启停。
- 单只股票范围必须填写股票代码；价格阈值必须大于 0；涨跌幅阈值范围为 -100% 至 100%。草稿启用不代表后台监控已运行。
- 本地草稿读写检查存储完整性与重复 ID；旧数据损坏时拒绝覆盖，避免静默丢失。
- 服务端规则 CRUD、后台评估、触发历史、通知渠道、收件箱与投递记录均未接入；本地草稿和通知偏好不代表真实监控或发送。

### 3.5 数据中心
- 检查 WebUI 页面可访问性。
- 检查行情服务 live/ready、分析服务 healthz/readyz。
- 读取 Provider 注册和静态能力清单。
- 区分服务健康、Provider 注册、能力声明、实际业务请求结果；当前数据中心不直连 MariaDB/Redis。
- 页面接入只读 `GET /api/v1/data-sources/diagnostics`，展示 `quote`、`daily_bars` 两类真实业务请求形成的进程内熔断统计；该接口只覆盖这两类服务端观测，不主动探测 Provider。
- 页面另接入 `POST /api/v1/data-sources/probe` 主动探测。用户显式点击后，可选择全部/核心能力、连通性/契约/质量/新鲜度/跨源对账/存储六类诊断维度、单项超时，以及可选市场板块和单只股票样本；不在打开数据中心或执行普通健康检查时自动访问上游。
- 主动探测逐项展示 Provider/能力状态、质量原因、HTTP/错误阶段、源端时间、可验证的总体覆盖率和跨源字段比较。未配置、不支持、跳过与失败分开显示；缺少可验证覆盖分母时不推算总体覆盖率。
- 页面接入 `GET /api/v1/data-sources/probe/history`，展示最近 20 批持久化探测结果。MariaDB 未配置或历史存储不可用时，历史读取会单独提示；历史接口 503 不会覆盖本次探测结果。
- 同花顺仍只由服务端管理第三方 API Key。WebUI 可通过主动探测检查服务端已启用的同花顺能力，但不会读取、保存或回显第三方 API Key；未配置凭据/被跳过不能直接判定为 Provider 故障。WebUI 行情服务 API Key 与同花顺第三方 API Key 是两种不同凭据。

## 4. 设置中心

设置中心当前包含 10 个分组：

1. 显示偏好：主题、涨跌颜色、数字精度、成交额/成交量显示单位、自选股排序/字段显示。
2. 连接与服务：行情 API 路径、行情 API Key、分析 API 路径、已保存配置检查、未保存草稿检查。
3. 浏览器本地数据：工作区 JSON 导入/导出、本地数据范围说明。
4. 基础设置：默认日 K 条数、复权方式；默认市场/交易所因缺少可验证的查询筛选语义而暂不可配置。
5. 数据源管理：展示当前服务端可返回的 Provider/能力信息；不能在浏览器端假保存 Provider 密钥。
6. AI 模型与问股：服务端未接入的能力明确标记待接入。
7. 通知渠道：服务端尚无渠道 CRUD、订阅管理、单渠道发送测试及投递记录 API；相关控件禁用并标记待接入。本地通知偏好只保存在当前浏览器，不代表服务端订阅或发送。；时间按当前设备本地时钟解释，支持跨午夜区间；开始和结束相同会拒绝保存
8. 任务调度：服务端任务调度能力需接口支持。
9. 选股默认项：当前规则执行能力仍待服务端闭环。
10. 安全与备份：明确浏览器本地数据和服务端数据边界。

## 5. 浏览器本地数据边界

- localStorage：主题、展示/查询偏好、连接路径、行情 API Key、自选股清单、最近任务引用、研究笔记及 Run 报告归档。
- 工作区 JSON 导出/导入包含主题、本地偏好、同源 API 路径、自选股、分组及证券归属、最近任务引用；旧版 v1/v2 文件缺少分组字段时回退到“未分组”。合并时保留两侧分组并由导入归属覆盖同证券归属，超过 12 组拒绝写入。工作区备份不包含 API Key、行情缓存、研究笔记、完整分析报告、服务器 .env 或数据库数据。研究报告归档独立保存在浏览器本地，当前不随工作区 JSON 导出。导入替换或合并均保留工作区范围之外的既有研究笔记和报告归档，不会清空这些本地数据。
- 导入前校验格式/版本/字段；支持替换和合并。合并按证券代码与任务标识去重，导入记录覆盖冲突项。
- 导入会保留当前 API Key；写入后逐项回读确认，失败时尝试回滚。
- 浏览器存储不可读或格式异常时，不允许执行危险合并或覆盖未知数据。

## 6. 页面状态原则

所有数据组件至少区分加载中、有效数据、空数据、错误、过期、降级、未知。接口未接入时展示“待接入”，不得使用演示数据冒充真实数据。unknown 不等于 0；能力声明不等于实时健康；fetch 时间不等于源端事件时间。

## 7. 主要前端模块

- web/src/api.js：HTTP 请求、认证头、参数校验与错误归一化。
- web/src/market-overview.js：指数、市场宽度、市场级资金流历史、板块、涨跌停池、人气榜。
- web/src/market-activity.js：龙虎榜、交易日历。
- web/src/stock-research.js：个股研究补充数据。
- web/src/data-center.js：服务检查、Provider 能力清单、被动熔断诊断、主动探测结果与历史批次。
- web/src/preferences.js：浏览器展示/查询偏好。
- web/src/watchlist.js、web/src/recent-tasks.js：本地自选与任务引用。
- web/src/task-workflow.js：分析任务阶段事件分页响应校验、Run 身份校验、事件去重与续读判断；`web/src/api.js` 为 Task/事件/Run 请求提供超时和 AbortSignal 支持。
- web/src/app.js：页面状态、事件绑定、任务流程和工作区备份。

## 8. 不在 WebUI 分支擅自实现的事项

行情 Provider、Go 路由、OpenAPI 服务端契约、数据库迁移、Docker Compose、Nginx 上游配置属于数据层/服务端/部署范围。WebUI 发现接口缺口时，记录到 API 清单和提测清单，不以浏览器本地数据伪装服务端功能。
