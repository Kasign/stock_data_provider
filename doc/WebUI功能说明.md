# WebUI 功能与页面说明

更新日期：2026-10-30
开发分支：feat/webui-market-data-console
技术栈：原生 HTML、CSS、JavaScript ES Modules；不使用 React。页面不伪造行情或服务端配置。

## 1. 产品目标

围绕国内 A 股市场观察、热点发现、个股研究、任务分析和持续跟踪形成工作台。WebUI 负责交互和展示；行情事实、数据来源、质量状态及分析任务结果以服务端真实响应为准。当前不提供券商交易下单能力。

## 3. 页面模块

### 3.1 市场总览
- 核心指数行情。
- 市场涨跌分布/宽度。
- 行业与概念排行。
- 涨停、跌停、炸板池。
- 个股人气/飙升榜。
- 市场时段状态、数据来源与质量提示。
- 不以涨跌分布推算资金流，不以单日快照伪造历史情绪曲线。

### 3.2 个股行情与研究
- 按中文名称、六位代码或标准代码搜索证券。
- 实时行情与日 K；支持前复权、后复权、不复权。
- 前端计算 MA、RSI、MACD 等技术指标；计算结果需基于有效日 K 数据。
- 个股档案、估值、财务、所属板块、公告、资金流和筹码分布按需加载。
- 保留源端时间、采集时间、来源、质量状态和降级原因。

### 3.3 自选股
- 最多 50 条本地自选股，支持搜索、别名、单只/批量移除、批量调整分组、快捷查询和分析。
- 批量操作只作用于当前筛选结果中显式勾选的股票；全选仅选择当前可见筛选结果。
- 支持按最近更新、代码、名称、最新价、涨跌幅、成交额、换手率排序及升/降序；行情排序只使用已加载的真实行情，缺失项始终排在末尾。
- 辅助字段支持勾选显示和上移/下移排序：添加/更新时间、行情快照、今日分析、任务状态、分析结果。
- 排序、显示字段与字段顺序保存在当前浏览器；工作区 JSON 支持备份/迁移。
- 研究列表不自动批量请求所有自选股；当前没有服务端自选股跨设备同步。

### 3.3.1 选股与筛选
- 本地条件支持涨跌幅、换手率、成交额、MA5、MA20，支持 AND/OR 组合；条件编辑后可保存为当前浏览器本地方案。
- 支持保存、更新、另存为、载入和删除本地筛选方案；最多 30 个，仅保存在当前浏览器。
- 全市场行情分页 API 返回真实股票行情和可选 MA5/MA20，但当前不提供服务端筛选条件、行业/概念筛选、扫描任务、候选理由或选股历史。WebUI 不会将当前页过滤结果称为全市场扫描。

### 3.4 分析任务
- 创建分析任务并跟踪 queued/running/partial/succeeded/failed 等状态。
- 按事件序号续读阶段事件，避免旧请求覆盖当前任务。
- 查询运行结果并生成本地 Markdown 报告。
- 最近任务最多保存 10 条浏览器引用，支持股票/任务 ID/状态/错误原因搜索、状态/类型和创建日期筛选；本地记录保留失败代码与限长错误摘要。任务本体和完整报告由分析服务持久化。\n- 当前没有服务端任务列表分页 API；本区不是服务端完整历史，超过本地最近 10 条或更换浏览器后无法从此处检索。

### 3.5 数据中心
- 检查 WebUI 页面可访问性。
- 检查行情服务 live/ready、分析服务 healthz/readyz。
- 读取 Provider 注册和静态能力清单。
- 区分服务健康、Provider 注册、能力声明、实际业务请求结果；当前数据中心不直连 MariaDB/Redis。
- 页面已接入只读 `GET /api/v1/data-sources/diagnostics`，展示 `quote`、`daily_bars`、`index_quotes`、`market_breadth`、`sector_rankings` 五类真实业务请求形成的进程内熔断统计；接口本身不主动探测 Provider。\n- 同花顺只展示服务端注册/启用状态和静态能力声明，不执行上游真实请求测试，不验证第三方 API Key；未配置 Key 不等同 Provider 故障。读取诊断快照所需的 WebUI 行情服务 API Key 与同花顺第三方 API Key 是两种不同凭据。

## 4. 设置中心

设置中心当前包含 10 个分组：

1. 显示偏好：主题、涨跌颜色、数字精度、成交额/成交量显示单位、自选股排序/字段显示。
2. 连接与服务：行情 API 路径、行情 API Key、分析 API 路径、已保存配置检查、未保存草稿检查。
3. 浏览器本地数据：工作区 JSON 导入/导出、本地数据范围说明。
4. 基础设置：默认日 K 条数、复权方式；默认市场/交易所因缺少可验证的查询筛选语义而暂不可配置。
5. 数据源管理：展示当前服务端可返回的 Provider/能力信息；不能在浏览器端假保存 Provider 密钥。
6. AI 模型与问股：服务端未接入的能力明确标记待接入。
7. 通知渠道：服务端尚无渠道 CRUD、订阅管理、单渠道发送测试及投递记录 API；相关控件禁用并标记待接入。本地通知偏好只保存在当前浏览器，不代表服务端订阅或发送。
8. 任务调度：服务端任务调度能力需接口支持。
9. 选股默认项：当前规则执行能力仍待服务端闭环。
10. 安全与备份：明确浏览器本地数据和服务端数据边界。

## 5. 浏览器本地数据边界

- localStorage：主题、展示/查询偏好、连接路径、行情 API Key、自选股清单、最近任务引用。
- 工作区备份不包含 API Key、行情缓存、完整分析报告、服务器 .env 或数据库数据。
- 导入前校验格式/版本/字段；支持替换和合并。合并按证券代码与任务标识去重，导入记录覆盖冲突项。
- 导入会保留当前 API Key；写入后逐项回读确认，失败时尝试回滚。
- 浏览器存储不可读或格式异常时，不允许执行危险合并或覆盖未知数据。

## 6. 页面状态原则

所有数据组件至少区分加载中、有效数据、空数据、错误、过期、降级、未知。接口未接入时展示“待接入”，不得使用演示数据冒充真实数据。unknown 不等于 0；能力声明不等于实时健康；fetch 时间不等于源端事件时间。

## 7. 主要前端模块

- web/src/api.js：HTTP 请求、认证头、参数校验与错误归一化。
- web/src/market-overview.js：指数、市场宽度、板块、涨跌停池、人气榜。
- web/src/market-activity.js：龙虎榜、交易日历。
- web/src/stock-research.js：个股研究补充数据。
- web/src/data-center.js：服务检查与 Provider 能力清单。
- web/src/preferences.js：浏览器展示/查询偏好。
- web/src/watchlist.js、web/src/recent-tasks.js：本地自选与任务引用。
- web/src/app.js：页面状态、事件绑定、任务流程和工作区备份。

## 8. 不在 WebUI 分支擅自实现的事项

行情 Provider、Go 路由、OpenAPI 服务端契约、数据库迁移、Docker Compose、Nginx 上游配置属于数据层/服务端/部署范围。WebUI 发现接口缺口时，记录到 API 清单和提测清单，不以浏览器本地数据伪装服务端功能。
