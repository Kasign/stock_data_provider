# 数据质量与状态契约

更新日期：2026-10-30

## 1. 责任边界

- Go 行情数据层负责 Provider 调用、数据标准化、单位归一、来源/时间/质量元数据、缓存与降级。
- WebUI 负责请求状态、用户交互、数据展示和错误提示，不重复推测服务端数据质量。
- 分析服务负责分析任务、阶段事件和完整运行结果；浏览器只保存最近任务引用。

## 2. 数据质量状态

| 状态 | 含义 | 前端处理 |
|---|---|---|
| valid | 数据通过当前质量校验 | 正常展示 |
| degraded | 数据可用但存在缺失、覆盖或来源限制 | 展示并提示降级原因 |
| stale | 使用过期缓存/旧版本 | 显示数据时间和过期状态 |
| invalid | 数据不满足契约或校验失败 | 不作为有效事实使用 |
| unknown | 无法确认数据质量或空结果语义 | 显示未知，不转换为 0 |

请求状态（loading/empty/error）与数据质量状态必须分开。HTTP 200 不等于质量 valid。

## 3. 时间语义

- 源端事件时间/行情时间：quote_time、provider_timestamp。
- 服务采集时间：fetched_at。
- 标准化时间：normalized_at。
- 历史版本系统观察时间：system_observed_at。
- 不得使用采集时间冒充源端事件时间；缺少精确源端时间时应保留 degraded/unknown。

## 4. 数值与单位

- 股票价格：CNY/股。
- 成交量：股。
- 成交额：CNY。
- 百分比字段：百分点；1.25 表示 1.25%，不是 0.0125。
- 资金流字段必须使用明确的资金流定义，不得用成交额代替净流入。
- 指数成交额若 Provider 未提供可验证单位，应保留 provider_defined，不得擅自归一为 CNY。

## 5. 空数据语义

- 空列表可能表示源端未提供、Provider 暂不可用、日期未发布或覆盖未确认。
- 只有 Provider 明确证明覆盖完整时，才能将空结果解释为“无事件/数量为零”。
- unknown、null、缺失字段不得默认为 0、正常、未停牌或没有风险。

## 6. 历史与复权

- 请求复权参数：none、forward_adjusted、backward_adjusted。
- unknown 仅为响应状态，不是请求参数。
- 日 K 的 as_of 是系统观察时间点，只能读取本地记录的历史版本；不能实时回源后冒充历史。
- 研究结论应保留参考时点、行情快照标识、数据质量和适用周期。

## 7. 错误与并发

- 统一错误信封：error.code、error.message，可包含 request_id。
- 前端保留 HTTP 状态、错误码和请求 ID，错误摘要限长。
- 搜索、行情和任务等异步请求应取消旧请求或使用 generation guard，避免迟到响应覆盖新上下文。
- 部分失败必须保留逐项状态，不能将部分成功伪装为整体成功。

## 8. 权威文件

- 行情 API：services/market-data/openapi.yaml。
- 行情路由：services/market-data/internal/httpapi/server.go。
- WebUI API 客户端：web/src/api.js。
- 数据层能力清单：GET /api/v1/data-sources。
- Provider 运行诊断：GET /api/v1/data-sources/diagnostics，当前只覆盖 quote/daily_bars 的进程内熔断器观测。
