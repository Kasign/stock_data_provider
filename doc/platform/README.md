## 维护规则

1. 项目级任务状态以 `doc/整体任务规划/**` 为唯一权威；模块总规划只细化模块执行状态。
2. 模块当前任务只保留《当前任务状态和进度.md》一个入口。
3. 任务历史保留完整执行记录；过时结论标记为历史，不静默覆盖或删除。
4. L1/A2/A3 分层验收，不能相互替代。
5. Server/消费者接入责任见独立责任矩阵，不转嫁为 Platform 本地开发任务。
