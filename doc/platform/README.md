# 公共平台开发文档

- 所属仓库：Kasign/stock_data_provider
- 所属分支：feat/platform-foundation
- 当前基线：以分支最新 HEAD 为准
- 当前目标：个人使用、单一所有者、少量服务与低并发
- 当前阶段：PLAT-002 按个人使用目标收敛设计，待评审

本目录是公共平台的唯一专项文档入口。平台的目标不是建设通用 SaaS 底座，而是为个人使用的股票研究系统提供足够可靠、性能可控、故障可定位的公共能力。

## 规则

1. 01 文档是任务状态唯一权威清单；08 文档是当前公共接口契约权威。
2. 目标设计不代表已实现；任务状态必须有代码、测试和必要的运行证据。
3. 先解决真实存在的安全、性能、可靠性和定位问题，不为假设中的高并发预建系统。
4. 优先使用 Go 标准库、现有 MariaDB/Redis 和成熟依赖；不引入没有明确收益的新基础设施。
5. 默认单实例、单所有者、少量内部服务。若未来出现多用户、多实例或更高并发，必须基于实际需求单独评审扩展。
6. 只在 feat/platform-foundation 实现公共平台；服务启动、全局路由、DI 和 Migration 总入口由服务端集成分支负责。
7. 不为了统一而搬迁领域代码；Data/News/Research 保留领域模型、Repository 和数据质量规则。
