# 转载关系断言生命周期

## 目标

转载关系不是可覆盖的普通边，而是不可变的业务断言历史。每次核验、修订或撤销都追加新断言，不回写既有记录。

## 领域规则

- 断言状态：proposed、confirmed、retracted。
- 每条断言记录 asserted_at（业务断言时间）和 observed_at（系统观察时间）。
- 修订/撤销通过 supersedes_relation_id 指向被替代断言；旧记录保持不变。
- 被替代断言必须存在、属于相同转载主体和关系类型，且不能已撤销。
- 一条历史断言最多有一个直接后继；禁止自我替代、缺失父断言和替代链循环。
- 仅未被替代的 confirmed 断言进入当前关系图；proposed 不作为已确认事实，retracted 不进入当前关系图。
- 当前关系图按有向无环图（DAG）校验。一个转载新闻主体可以关联多个不同原始新闻主体；拒绝重复当前边和循环。
- 版本证据必须成对绑定转载方和原始方版本；任一侧变化后标记 stale，不自动改写历史证据。

## 验收边界

本批只完成 Domain 规则，不表示 Application 生命周期或生产 Repository 已完成。后续 Application 必须在同一事务中读取完整关系历史、校验替代链与证据归属并追加新断言。生产数据库应对 supersedes_relation_id 建立唯一约束，并在事务冲突时返回可识别的领域冲突。
