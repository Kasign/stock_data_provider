### 本任务允许范围

- 只读核对 `internal/news/app`、`internal/news/domain` 与 Server/Researchflow 现有调用路径。
- 明确 CollectionRunID 是否属于 News 领域身份，以及它与 RequestID、Researchflow RunID、AttemptID、Observation ID 的关系。
- 明确一次采集执行的触发方、批次边界、重放/幂等作用域、失败/取消语义和 Worker 传播方式。
- 形成依赖/决策文档，更新模块总规划和当前任务状态。

### 本任务禁止范围

- 未确认 Owner 前不新增 CollectionRunID 字段、接口、表或 Migration。
- 不借用 Researchflow RunID/AttemptID 作为 News 领域采集身份。
- 不新建通用 Scheduler、Task Queue、独立 HTTP API 或 Service Key。
- 不修改 `cmd/**`、`internal/server/**`、`internal/platform/**` 或其他模块。
- 不以固定 Fixture 或 Stage 搜索候选冒充 Source Feed 真实采集验收。

### 退出条件

1. CollectionRunID Owner、生成方和唯一性/幂等作用域明确。
2. 触发入口和调用方明确，且有真实调用场景。
3. 标识符来源、语义、传播、保留期限和关联对象明确。
4. Server/News 各自责任与必要的公开 Port 变更明确。
5. 对应设计与依赖文档完成评审；若仍无 Owner 决议，任务保持 BLOCKED，不开始代码实现。
