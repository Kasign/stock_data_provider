# 新闻来源授权矩阵

> 核查日期：2026-11-05
> 状态：第一轮公开条款核查；不是法律意见，不等于已取得任何来源的书面授权
> 适用范围：个人低频 A 股研究助手；不默认对外分发、商业转售或向多租户提供新闻内容

## 1. 使用原则

必须将两类授权拆开判断：

1. **Provider 输出使用权**：新闻搜索/聚合 API 是否允许使用、缓存、保存或再分发它返回的候选结果。
2. **原始发布来源内容权利**：新闻发布者、监管机构、交易所或信息披露平台是否允许抓取、保存摘要/正文、建立历史数据库及向用户展示。

Provider 允许保存输出，不代表原始发布者允许保存其文章全文；Provider 不允许保存结果，也不能通过随后抓取原始 URL 来绕过 Provider 自身的使用限制。

来源可访问、存在 RSS、内容公开或用于投资研究，都不能单独推导出自动抓取、长期保存、再分发或训练模型的授权。

### 2.1 Provider 规则的实现含义

- Provider 结果和发布来源内容必须有独立策略判断，不能用一个 `persist_allowed` 布尔值概括。
- 搜索候选可临时进入当前请求的内存处理流程；是否允许持久化 observation、标题、摘要、URL、全文，按 Provider 输出条款和来源内容权利分别判断。
- 对 Brave，持久化 Search Results 不允许；对博查，存储权利未明确前不持久化；对 Tavily，Provider 层存储许可不能覆盖第三方发布者版权。
- 不允许将“先从受限 Provider 搜到 URL，再抓取原文”的路径作为规避 Provider 结果限制的手段。若使用第三方搜索结果进行跳转，须确保仅作必要的临时定位，并由独立来源策略决定是否可形成新闻事实记录。
- Provider 条款、套餐、Order Form 或企业补充协议可能变化；上线前应核对实际账号适用版本，而不是只依赖公共网页。

## 4. 媒体、行业站点和聚合源

- 媒体/行业网站必须逐个记录发布者、服务条款、版权声明、robots 规则、允许访问方式、内容类型、留存范围和复核日期。
- RSS/Atom 只说明存在订阅格式，不自动授予服务端长期保存全文、建立数据库或再分发的权利。
- robots.txt 是自动化访问规则信号，不等同于版权许可或合同授权；两者都要检查。
- NewsNow 等聚合器必须进一步追溯实际上游发布者；聚合器可访问不代表聚合器拥有第三方内容授权。
- 没有明确许可的来源，默认只保留必要的来源名称/链接等最小定位信息是否可行也需逐源确认；不能把“只存 URL”当成无条件免责方案。
- 不把摘要改写、提取事实或模型生成摘要视为自动脱离原始内容权利约束。

## 5. 建议的策略状态与默认动作

| 状态 | 含义 | 默认动作 |
|---|---|---|
| approved | 已核验具体协议/授权，覆盖指定访问方式、字段、保存用途和期限 | 仅在授权范围内采集和保存 |
| restricted | 有明确限制，例如禁止长期保存或禁止自动化访问 | 按限制缩小为临时使用/禁止抓取/禁止持久化 |
| pending | 条款不明确、未找到条款或需要书面确认 | 禁止自动化抓取和持久化内容 |
| revoked | 授权撤销、到期或来源要求停止 | 停止新增采集，按约定清理受影响载荷并保留必要审计记录 |

策略至少按以下维度表达，不得仅按来源名称设置一个总开关：

- 访问方式：manual / official_api / rss / scripted_web / licensed_feed。
- 可采集内容：metadata / title / snippet / abstract / full_text / attachment。
- 可保存内容：none / transient / persistent_metadata / persistent_excerpt / persistent_full_text。
- 用途：internal_personal_research / internal_business / public_display / redistribution / model_training。
- 保留期限、缓存期限、删除要求、署名要求和来源链接要求。
- 授权依据 URL、协议版本/日期、核验人、核验时间、适用账号/套餐及复核时间。

同一来源的访问许可和内容保存许可必须分别判断；Provider 许可和发布者许可必须同时满足。

## 6. 当前默认接入策略

1. SEC/EDGAR：优先纳入官方数据接入候选；按 User-Agent 和速率政策访问，记录内容类型和第三方材料边界。
2. Tavily：可用于候选发现和 Provider 输出保存；每条原始发布来源仍需通过来源策略判断后才能保存摘要/正文。
3. Brave：只作临时搜索候选，不持久化 Brave API 输出。
4. Bocha：等待书面确认结果存储权利；确认前不持久化其搜索输出。
5. HKEX：未获得书面许可前不做服务端自动采集或内容持久化。
6. SSE：自动化采集许可待确认；当前不批量抓取和全文入库。
7. SZSE/CNINFO：优先核实官方数据服务产品/协议；未确认前不将网页访问视为自动采集授权。
8. SearXNG、NewsNow 和媒体网站：逐实例/逐上游/逐发布者核验，不继承聚合器的授权假设。

## 9. Source/Endpoint 策略继承规则

- Source 级策略为默认规则，适用于该发布者所有入口。
- Endpoint 级策略只在某入口有独立条款/授权/访问限制时建立，不复制相同内容。
- Endpoint 级规则默认只能收紧 Source 级权限；扩大权限必须有单独书面许可及明确适用范围。
- 未配置 endpoint 级策略时继承 source 级策略；source 级策略 pending 时不得自动采集。
- 最终权限是 Provider 输出策略、Source 策略、Endpoint 策略、使用目的和保留期限的交集。
