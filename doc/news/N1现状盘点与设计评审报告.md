### 3.2 生产链路未形成

当前代码可确认：

- `CollectSource` 从 SourceCatalog 获取登记来源/Endpoint，执行 URL 离线校验、授权评估和 RSS/Atom 解析，返回 transient Entry。
- `CollectSourceResult.ObservationPolicyTrace()` 能传递本次策略版本评估证据。
- `IngestCandidate.ExecuteWithPolicyTrace` 能执行来源内身份解析和 Observation 追加。
- `ApplyResearchUpdate` 要求已有持久化 ObservationID/NewsID，执行内容版本和关系断言追加。

但尚无生产编排将它们连接起来。专项测试的手工串联只证明组件协作，不证明真实触发器、批次身份、Repository 或生产事务存在。

目标链路仍缺：

`Source Trigger → CollectionRunID → CollectSource → IngestCandidate → Observation → ApplyResearchUpdate → Query`

当前没有 CollectionRunID 的真实所有者。不得使用 Analysis RunID 替代，也不得在没有调用方时提前添加无主的 RunID/key builder。

最新身份修正（`3afc7a7132`）要求候选凭据 Hash 与原文一致；已存记录原文相同但 Hash 不一致时返回 `news.identity.stored_hash_mismatch`，并新增回归测试。最新授权修正（`aca8ff6b6b`）要求非 null `expires_at` 严格晚于 `decided_at`，拒绝零有效期授权快照，并增加对应测试。两项均保持 fail-closed，不改变生产 Repository 缺失的结论。

## 4. 公共平台合并后的真实状态

### 4.1 PLAT-008 HTTP Client / BoundDoer

当前分支已经包含：

- `internal/platform/httpclient/client.go`
- `internal/platform/httpclient/bound_doer.go`
- `internal/platform/httpclient/address.go`

`Client.Bind(DestinationPolicy)` 返回 `BoundDoer`；`BoundDoer.Do(*http.Request)` 与 News `app.HTTPDoer` 接口完全兼容。News `EndpointTransport` 和 Provider Adapter 可直接接收该窄接口，不需要改造接口或自建 HTTP Client。

平台 Client 已有精确 Host/Port 策略、DNS/IP 校验、校验地址绑定实际 Dial、禁用环境代理、受控重定向、响应体上限、Deadline、依赖并发和有限重试等实现。

平台文档记录 BoundDoer 专项验证提交 `3e8f197a8b10ef2584fdc24870043eeb329f854e`，CI Run `42005639102` 成功。此为平台受控测试证据，不代表 News 已生产注入或生产公网 DNS/egress 已验收。

**News 尚缺：**

- 根组合根为每个 Provider API endpoint 分别调用 Bind，注入独立 BoundDoer。
- 每个 Source/Endpoint 分别绑定固定策略；不能复用 Provider endpoint allowlist。
- 组合根不允许把裸 `http.Client` 注入生产 Provider/Source。
- 真实 Provider/Source 网络和部署 DNS/出口验收。

### 4.2 PLAT-009 Storage / Migration

当前分支已经包含 `internal/platform/storage/storage.go`，提供：

- `OpenSQL` / `OpenRedis`：连接生命周期和 Ping。

## 9. 设计评审结论

### 9.1 维持的架构决策

本轮没有发现需要推翻 News 总体架构的理由，以下决策继续成立：

- 根 Go Module 内模块化单体，News 通过同进程 Application 提供能力。
- 不新增新闻独立服务、端口、公网 HTTP Server 或旧 Python 兼容层。
- Domain/Application/Adapter 分层；Provider Adapter 不复制旧 Searcher 的缓存、聚合、fallback 和旧 DTO。
- Provider 与 publisher/source 身份分离；Provider 输出许可和原始来源内容许可独立判断。
- Source/Endpoint 策略按交集评估，Endpoint 默认只能收紧。
- 时间、身份、Observation、版本和关系证据保持可追溯，不伪造发布时间和历史版本。
- News 拥有自己的 Repository、SQL、业务表、索引和 Migration；Platform 提供连接生命周期与 Migration Runner。
- Server 组合根负责共享 DB/Redis/HTTP Client 生命周期、Config/Secret、Migration 注册和路由。
- Python 旧链路仅作为历史能力/数据语义参考，不双写、不做兼容切换、不负责旧服务退役。
