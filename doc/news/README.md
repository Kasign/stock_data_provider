## 维护规则

1. 新任务必须先在模块总规划中分配唯一编号，再进入当前任务文档。
2. 同一时刻只能有一个当前任务；任务切换时先关闭当前任务，再更新唯一当前任务入口。
3. 历史文档保留完整执行记录；历史状态不覆盖当前状态。
4. 项目级契约定义和 L1 冻结状态以 `doc/contract/PLAT-002-项目级契约冻结登记簿.md` 为准。
5. 任务完成必须有精确 SHA 和对应验收证据；真实网络/数据验收必须有真实来源、授权与运行证据。
