## 维护规则

1. 同一时刻只能有一个当前执行任务。
2. 当前业务规则只维护在本目录的当前契约中；旧规则直接替换或删除。
3. 不保留已取消能力的设计文档、空实现说明或兼容计划。
4. 任务完成必须记录精确 SHA 和验收证据；CI 未完成不得标记 DONE。
