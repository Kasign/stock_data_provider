## 维护规则

1. 总体任务和当前状态分别由两个任务文档维护。
2. 历史阶段任务与验收证据统一归入任务历史。
3. available_at 必须有真实来源证据；不得从发布时间、抓取时间或观察时间推导。
4. News Search Stage 不等于持久化新闻采集或 Research Evidence 写入。
