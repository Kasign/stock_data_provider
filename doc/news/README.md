## 目标

建设 A 股低频研究助手的新闻基础设施：来源接入、内容采集、标准化、去重、版本留存、证券关联、质量诊断和查询 API。

本专项采用模块化单体：新闻业务模块位于根 Go 模块，由 `stock-analysis-server:8092` 统一组装和部署；不新增独立微服务、端口或部署入口。新闻模块内部调用不单独设置认证，所有对外 HTTP 访问统一经过 Server 的安全边界。

## N1 已确认的架构决策（2026-11-05）

- **部署位置：** 根目录统一部署的 `stock-analysis-server:8092`。
- **模块边界：** 新闻业务模块位于根 Go 模块（建议落点 `internal/news/`），由 `cmd/analysis-api` 组装；不放入 `go-core` 或 `services/market-data`。
- **内部调用：** 同进程模块通过 Application 接口直接调用，不经过内部 HTTP，不设置新闻专属 Service Token。
- **对外入口：** 不新增新闻独立服务、端口或部署入口；需要对外提供的新闻 HTTP 路由统一注册到主 Server。
- **认证责任：** 新闻模块不重复实现认证，统一依赖 Server 的认证与权限边界。当前根 API 尚未发现认证中间件，因此来源管理、主动采集、外部 URL 测试等管理操作，在 Server 级认证和管理员授权实际落地前不得作为无保护公网接口开放。
- **阶段边界：** 本决策只冻结部署归属和认证责任边界，不代表 Server 认证已经实现，也不代表新闻 API、业务代码或数据库已实现。N1 其余未决项仍需完成评审。
