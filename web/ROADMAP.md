## 产品结构

1. **首页/市场总览**：指数、市场广度、市场情绪、成交与资金、热点板块多维榜、涨跌停/人气榜、龙虎榜和交易日历；全球市场先占位，等待数据源与时区契约。
2. **个股研究**：搜索/自选/最近研究列表 + 专业详情，详情整合行情、技术、财务、估值、资金与筹码、公告、来源和质量。
3. **自选股**：关注状态、今日分析、活动任务和最新结果。当前是浏览器本地清单，不是服务端同步。
4. **分析任务**：创建任务与任务列表，任务详情包含结果摘要、运行流和诊断；运行流不是单独的主导航。
5. **条件选股**：保留规划入口。策略 schema、扫描任务、候选解释、历史 API 未到位前不显示假结果。
6. **数据中心**：服务存活/就绪、MariaDB/Redis 依赖、Provider 能力声明和“立即检查”；逐 Provider 真实探测要以后端诊断 API 为依据。
7. **设置与扩展**：按连接、界面偏好、数据偏好、诊断分组。问股、通知、告警等在真实 API 接入前保持规划状态。

## 分期

### P0：调整现有页面排版
统一首页、个股研究、自选股、分析任务/详情内运行流、数据中心和设置的标题、卡片/表格、信息层级和状态表现。可以先为尚无数据的模块准备 UI，但必须显示规划/不可用状态；不得编造行情。

### P0：数据中心立即检查
使用当前 health/readiness 接口与 Provider 清单展示已有证据；明确能力声明不是实时健康。逐 Provider/能力检查应有受保护的后端 API、并发上限、超时、速率限制和安全错误摘要。

### P1：国内 A 股数据能力
补齐情绪历史快照、市场/板块资金净流入、完整的板块多维排序与近五日数据、股票批量概览和逐 Provider 实际诊断。

### P2：全球市场
确认数据源可达性/授权、延迟、指数范围、币种、交易时区、交易时段和质量规则后接入。

## 数据真实性原则

- 接口路由存在不代表生产 Provider 已通过验收。
- 成交额不是资金净流入；当前快照不是历史趋势。
- Provider 配置不是实时健康；HTTP 成功不代表数据质量有效。
- 本地任务引用不是服务端历史；规划占位不是已实现能力。
- 缺失、0、未知、未配置、失败、降级和确定空必须分别表达。

之前的单股分析闭环路线与下方历史记录不再代表当前优先级。历史实现过程继续记录在 `PROGRESS.md`。
