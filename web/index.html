连接与密钥设置

        
默认路径由 WebUI 的 Nginx 反向代理转发。密钥只保存在当前浏览器 localStorage，不写入仓库或服务端配置。

        

          
API 和数据分别存在哪里？

          
当前 WebUI：只负责页面和请求转发，不直连数据库。API Key、自选股和最近任务引用保存在当前浏览器；最近任务列表最多 10 条，不保存完整报告。

          
Go 行情服务：负责请求和归一化行情 Provider 数据，按自身配置使用独立的 MariaDB/Redis。具体行情记录是否持久化取决于后端接口实现。

          
Go 分析服务：分析任务、阶段事件、Run 结果及快照由后端持久化到 MariaDB；Redis 用于缓存结果/快照，MariaDB 是最终事实源。

        

        
        
        
这是部署管理员自行生成的服务访问密钥，不是第三方行情 Provider 的密钥。将同一个值配置为部署仓库根目录 .env 中的 MARKET_DATA_API_KEY（Go 行情服务与分析服务共用），可在服务器终端执行 openssl rand -hex 32 生成。这里仅保存到当前浏览器 localStorage，不会自动修改服务器配置或生成后端密钥。

        
        
安全提示：不要将带有 API Key 的浏览器会话分享给他人。对公网部署前，应在 OpenResty 或身份认证层增加访问控制；行情服务密钥本身不等于用户认证。
