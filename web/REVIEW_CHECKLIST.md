## 已完成的源码 Review 与改进

| 项目 | Review 结论 | 本轮处理 |
|---|---|---|
| 主导航与功能边界 | 行情与任务是当前可执行的主要工作流；通知、问股、选股、告警仍缺真实后端资源 | 保留导航和“待接入”提示，不伪造数据或开放写操作 |
| 全局刷新入口 | 非行情/任务页面的刷新按钮原先仍叫“刷新数据”，实际只重查两个服务的健康状态 | 根据当前视图动态更新按钮的无障碍名称和提示；明确写出当前页接口待接入时只检查连接 |
| 重复刷新请求 | 顶栏刷新按钮原先没有自己的进行中锁，快速连点可能重复触发健康检查和刷新链路 | 刷新期间禁用按钮，设置 `aria-busy`，结束后恢复当前页面对应的说明 |
| 禁用控件语义 | 禁用按钮的光标原先为 `wait`，容易与加载状态混淆 | 禁用控件统一使用 `not-allowed`；仅刷新过程使用 `progress` |
| 键盘可访问性 | 原有焦点样式覆盖主要输入与按钮，原生 `summary` 需要有一致的可见焦点提示 | 将 `summary:focus-visible` 纳入基础焦点规则 |
| 过期/旧请求结果 | 主行情、个股研究和市场总览已有请求代次/取消保护；新个股查询会先清理旧行情及日 K | 保留既有保护逻辑，不改其状态契约 |
| API 失败状态 | 已有逻辑可区分未接入（404）、Provider 不可用（503）、鉴权失败（401/403）及普通错误；市场总览有刷新结果汇总 | 不引入新的状态推断，不把空数据解释为零或“市场没有记录” |
| Run Flow | 以服务端 StageEvent 作为真实时间线；当前无可信 DAG 拓扑快照 | 保留线性事件时间线，不绘制虚构节点、进度百分比或依赖边 |
| CSS 维护性 | `styles.css` 仍包含分散媒体查询；原快速定位和首页快捷卡片规则已因信息架构调整移除 | 清理无用组件和精确重复的顶层规则；保留其余断点与规则顺序，不跨区块合并以免改变级联 |

## 仍需浏览器 / NAS 验收

本清单记录源码 Review 与自动化验收边界。`42c6d41` 对应的 [Chromium 浏览器烟测](https://github.com/Kasign/stock_data_provider/actions/runs/40441039966) 已通过七种视口检查，但 API 被明确设为 503；**这不代表真实业务 API、深浅主题人工视觉或 NAS/Docker 已验收**。

| 视口宽度 | 必查内容 |
|---:|---|
| 320 px | 顶栏图标与面包屑不互相挤压；日期控件、表单、弹窗无页面级横向溢出 |
| 375 px | 移动导航打开/关闭、点击导航后抽屉关闭、主题切换与触控区域 |
| 600 px | 移动布局断点边界、市场榜单、行情卡片与图表 |
| 768 px | 图标侧栏、市场双列区块、最近任务和设置表单 |
| 900 px | 侧栏断点、页头操作区换行、任务抽屉标题和筛选器 |
| 1280 px | 桌面导航、查询工具栏、市场榜单表格与密度 |
| 1600 px | 内容最大宽度、留白、图表和数据卡片比例 |

其他人工场景：深色/浅色主题；键盘从导航进入主内容；`Tab` 聚焦原生折叠区标题；减少动画偏好；API Key 缺失；404/503/401/403；网络失败；模块首次加载为空；新查询失败后旧数据不会残留；任务流事件筛选与抽屉关闭；通知/问股/选股/告警明确显示接口未接入。部署侧需确认反向代理前缀、API Key 转发及服务名与根目录配置一致。

## 后端依赖边界

通知收件箱、Agent Chat/会话/流式输出、选股策略/候选/历史、告警规则与触发记录、服务端设置读写、任务列表和 Run Flow DAG 快照仍需后端 API/契约支持。前端只能显示能力状态与清晰空态；不能使用 localStorage 冒充服务器持久化，也不能将测试 fixture 当作线上结果。
