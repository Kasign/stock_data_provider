## Worker deadline 测试时序缺陷
- 根因：`TestWorkerConvertsAttemptDeadlineIntoPolicyControlledTimeout` 用真实 `time.Now()` 构造 `Attempt.StartedAt`，再以 1ms attempt timeout 验证转换；CI 上加载快照与 claim 超过 1ms 时在 executor 前命中 `ErrWorkerDeadline`。
- 修复：固定 `databaseNow`，同步设置 `Attempt.StartedAt`、`Run.DeadlineAt`、`workerClockFake.now`；断言强度不变。变异关闭 attempt timeout 转换分支后用例失败，恢复后连续 200 次 PASS。
- 本地全仓 `go test ./... -count=1`、`go vet ./...`、`git diff --check` 通过；CI 按新 SHA 回填。
